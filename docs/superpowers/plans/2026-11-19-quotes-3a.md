# Module 3a: Quotes (staff side) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Staff build a quote on a phone for one customer and one property, issue it (numbered, frozen), download it as a PDF, revise or withdraw it, and record or reverse the client's acceptance. Accepting makes a lead active and makes the quote the property's agreed scope. Phase 3b (private client link) is a separate plan.

**Architecture:** Business rules live in `packages/core/src/quotes/` as plain functions taking a database handle plus an `Actor` and checking the role first, exactly like customers and services. Pure rules (totals, references, validation, the document model) are unit tested; database behaviour is tested against the dev database in always-rolled-back transactions. The admin app gets a Quotes list, a phone-first builder that autosaves, a quote page with actions, a PDF route, and an owner-only quote wording page.

**Tech Stack:** Next.js 16.4 (App Router, server actions), React 19, TypeScript strict, Prisma 7 with `@prisma/adapter-pg`, Supabase Postgres, zod 4, vitest 5, Tailwind 4, `@react-pdf/renderer`.

**Spec:** `docs/superpowers/specs/2026-11-19-quotes-design.md` (read the Quote content, Data model, Status rules, Quote wording, Screens and Privacy sections; this plan implements phase 3a only).

## Global Constraints

- Not VAT registered; money is whole cents (`Int`), shown with `formatZAR` ("R1,234.56"). No VAT anywhere. Amounts typed in rand are converted with `parseRandToCents` (already in `packages/core/src/customers/schemas.ts`).
- Every new table: Row Level Security enabled, no policies, privileges revoked from `anon` and `authenticated`. Only server code reads or writes.
- Every protected page, server action and route handler calls `requireStaff(["OWNER","MANAGER"])` (the `MANAGEMENT` roles) first; the quote wording page and reversing an acceptance are OWNER only (`requireStaff(["OWNER"])`). Every core function calls `assertRole(...)` as its first line. Crew get no access to quotes or prices.
- **Audit entries hold field names, ids and fixed words only (counts, methods, statuses), never personal values or typed free text** (names, notes, reasons, addresses). Draft autosaves are not audited.
- A save that changes nothing writes nothing: no database write, no `updatedAt` change, no audit line (drafts: the version number does not move either).
- Client components never import values from `@ace/core`; they import from `@ace/core/client` (browser-safe).
- Every page works at phone width (375px) with no sideways scrolling; interactive controls are at least 40px high or wide.
- Copy rule: no em dashes in any text shown on screen or printed on a quote.
- Customers are archived, never deleted. Issued quotes are never deleted (only never-issued drafts can be).
- No real client data in git, tests or the dev database. Tests use made-up customers; DB tests run only against the DEV database inside always-rolled-back transactions (`npm run test:db`); CI skips them.
- Code style: Prettier, ESLint clean, `noUncheckedIndexedAccess` is on.
- **Formatting rule:** never run the root `npm run format` (it rewrites unrelated files because of Windows line endings). Format only the files you touched: `npx prettier --write <paths>`. `npm run check` must pass at the end (its format check covers only committed content).
- Windows: PowerShell needs `npm.cmd`; Git Bash is fine with `npm run`.
- Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Commit locally after each task. Do not push. Do not apply any migration yourself (the controller does, after the owner approves).
- Next.js 16 specifics already used here: `params` and `searchParams` are Promises (`await` them); server actions live in `"use server"` files that export only async functions; server actions may also be called from client components with serialisable arguments.
- Do not run `npm run build` while a dev server is running (it overwrites `.next`).

export type QuoteStatusValue =
  | "DRAFT"
  | "ISSUED"
  | "ACCEPTED"
  | "DECLINED"
  | "REPLACED"
  | "WITHDRAWN";
export type QuoteDisplayStatus = QuoteStatusValue | "EXPIRED";

const ZONE = "Africa/Johannesburg";
// The "en-CA" locale formats a date as YYYY-MM-DD.
const dayFormat = new Intl.DateTimeFormat("en-CA", {
  timeZone: ZONE,
  year: "numeric",
  month: "2-digit",
  day: "2-digit",
});

/** Today's date in South Africa as "YYYY-MM-DD", wherever the server happens to run. */
export function todaySA(now: Date = new Date()): string {
  return dayFormat.format(now);
}

export function yearSA(now: Date = new Date()): number {
  return Number(todaySA(now).slice(0, 4));
}

/** A date column (stored as midnight UTC) as "YYYY-MM-DD". */
export function toDateString(date: Date): string {
  return date.toISOString().slice(0, 10);
}

export function fromDateString(value: string): Date {
  return new Date(`${value}T00:00:00.000Z`);
}

export function isValidDateString(value: string): boolean {
  if (!/^\d{4}-\d{2}-\d{2}$/.test(value)) return false;
  const date = fromDateString(value);
  return !Number.isNaN(date.getTime()) && toDateString(date) === value;
}

export function addDays(value: string, days: number): string {
  const date = fromDateString(value);
  date.setUTCDate(date.getUTCDate() + days);
  return toDateString(date);
}

/** "QUO-2026-0104", with " R2" from the second revision on. Null for a draft (no number yet). */
export function formatQuoteReference(q: {
  numberYear: number | null;
  numberSeq: number | null;
  revision: number;
}): string | null {
  if (q.numberYear === null || q.numberSeq === null) return null;
  const base = `QUO-${q.numberYear}-${String(q.numberSeq).padStart(4, "0")}`;
  return q.revision > 1 ? `${base} R${q.revision}` : base;
}

/** ISSUED quotes whose valid-until day has passed show as EXPIRED. Nothing is stored for this. */
export function displayStatus(
  q: { status: QuoteStatusValue; validUntil: Date },
  today: string = todaySA(),
): QuoteDisplayStatus {
  if (q.status === "ISSUED" && toDateString(q.validUntil) < today) return "EXPIRED";
  return q.status;
}

export type TotalsLine = {
  lineKind: "PRICED" | "OPTIONAL" | "INCLUDED";
  billing: "MONTHLY" | "ONCE_OFF" | null;
  amountCents: number | null;
  chosen?: boolean;
};

export type QuoteTotals = {
  monthly: number;
  onceOff: number;
  optionalMonthly: number;
  optionalOnceOff: number;
  monthlyWithOptions: number;
  onceOffWithOptions: number;
};

function sum(lines: readonly TotalsLine[], kind: TotalsLine["lineKind"], billing: string): number {
  return lines
    .filter((l) => l.lineKind === kind && l.billing === billing)
    .reduce((total, l) => total + (l.amountCents ?? 0), 0);
}

/** Everything is whole cents. Optional add-ons are never part of `monthly` or `onceOff`. */
export function quoteTotals(lines: readonly TotalsLine[]): QuoteTotals {
  const monthly = sum(lines, "PRICED", "MONTHLY");
  const onceOff = sum(lines, "PRICED", "ONCE_OFF");
  const optionalMonthly = sum(lines, "OPTIONAL", "MONTHLY");
  const optionalOnceOff = sum(lines, "OPTIONAL", "ONCE_OFF");
  return {
    monthly,
    onceOff,
    optionalMonthly,
    optionalOnceOff,
    monthlyWithOptions: monthly + optionalMonthly,
    onceOffWithOptions: onceOff + optionalOnceOff,
  };
}

/** After acceptance: the priced lines plus the optional add-ons the client actually chose. */
export function acceptedTotals(lines: readonly TotalsLine[]): { monthly: number; onceOff: number } {
  const counted = lines.map((l) =>
    l.lineKind === "OPTIONAL" ? (l.chosen ? { ...l, lineKind: "PRICED" as const } : l) : l,
  );
  const totals = quoteTotals(counted);
  return { monthly: totals.monthly, onceOff: totals.onceOff };
}

export function validateForIssue(
  input: { validUntil: string; scope: { included: boolean }[]; lines: IssueLine[] },
  today: string,
): string[] {
  const problems: string[] = [];
  if (!input.scope.some((s) => s.included)) problems.push("Switch on at least one service.");
  if (input.validUntil < today) problems.push("The valid-until date must be today or later.");
  input.lines.forEach((line, index) => {
    const n = `Line ${index + 1}`;
    if (!line.description.trim()) problems.push(`${n} needs a description.`);
    if (line.lineKind === "INCLUDED") return;
    if (!line.billing) problems.push(`${n} needs monthly or once-off.`);
    if (line.amountCents === null || line.amountCents <= 0) {
      problems.push(`${n} needs an amount above zero.`);
    }
    if (
      line.lineKind === "PRICED" &&
      line.billing === "MONTHLY" &&
      (line.frequency === null || line.frequency === "AS_REQUIRED")
    ) {
      problems.push(`${n} needs how often (weekly, every two weeks or monthly).`);
    }
  });
  if (!input.lines.some((l) => l.lineKind === "PRICED")) {
    problems.push("Add at least one monthly or once-off price.");
  }
  return problems;
}

import { createHash } from "node:crypto";

/** JSON with sorted keys, so equal content always produces equal text. */
export function stableStringify(value: unknown): string {
  if (value === null || typeof value !== "object") return JSON.stringify(value);
  if (Array.isArray(value)) return `[${value.map((v) => stableStringify(v)).join(",")}]`;
  const entries = Object.entries(value as Record<string, unknown>)
    .filter(([, v]) => v !== undefined)
    .sort(([a], [b]) => (a < b ? -1 : a > b ? 1 : 0))
    .map(([k, v]) => `${JSON.stringify(k)}:${stableStringify(v)}`);
  return `{${entries.join(",")}}`;
}

/** SHA-256 of the canonical content: the fingerprint of exactly what a quote said. */
export function contentHash(content: unknown): string {
  return createHash("sha256").update(stableStringify(content)).digest("hex");
}

import { recordAudit } from "../audit";
import { DomainError, type Actor } from "../customers/access";
import type { Db } from "../db";
import type { Prisma } from "../generated/prisma/client";

/** What the quote functions need. Works with the normal connection or a transaction. */
export type QuoteStore = Pick<
  Db,
  | "quote"
  | "quoteScopeItem"
  | "quoteLine"
  | "quoteWording"
  | "quoteCounter"
  | "service"
  | "customer"
  | "contact"
  | "property"
  | "auditLog"
  | "organisationSettings"
  | "$queryRaw"
>;

/** Two people saved the same draft; the later one must reload instead of overwriting. */
export class DraftConflictError extends DomainError {
  constructor() {
    super("This quote was changed somewhere else. Reload the page to see the latest version.");
    this.name = "DraftConflictError";
  }
}

export const QUOTE_INCLUDE = {
  scopeItems: { orderBy: { sortOrder: "asc" } },
  lines: { orderBy: { sortOrder: "asc" } },
} as const satisfies Prisma.QuoteInclude;

export async function findQuote(store: QuoteStore, id: string) {
  const quote = await store.quote.findUnique({ where: { id }, include: QUOTE_INCLUDE });
  if (!quote) throw new DomainError("That quote could not be found.");
  return quote;
}

/**
 * Locks the quote row until the transaction ends, by touching it, so two people changing the same
 * quote take turns. Call it only when something is really about to be written.
 */
export async function lockQuote(store: QuoteStore, id: string): Promise<void> {
  const { count } = await store.quote.updateMany({ where: { id }, data: { updatedAt: new Date() } });
  if (count !== 1) throw new DomainError("That quote could not be found.");
}

/** The customer and property a quote may be written for. */
export async function requireQuotable(store: QuoteStore, customerId: string, propertyId: string) {
  const customer = await store.customer.findUnique({
    where: { id: customerId },
    select: { id: true, status: true, anonymisedAt: true },
  });
  if (!customer) throw new DomainError("That customer could not be found.");
  if (customer.anonymisedAt) {
    throw new DomainError("This customer has been anonymised and cannot be quoted.");
  }
  if (customer.status === "ARCHIVED") throw new DomainError("Restore this customer before quoting.");
  const property = await store.property.findUnique({ where: { id: propertyId } });
  if (!property || property.customerId !== customerId || property.archivedAt) {
    throw new DomainError("Choose one of this customer's properties.");
  }
  return { customer, property };
}

/** Writes an audit line about a quote. `after` holds field names, ids and fixed words only. */
export async function logQuoteEvent(
  store: QuoteStore,
  actor: Actor,
  action: string,
  quoteId: string,
  after?: Prisma.InputJsonValue,
): Promise<void> {
  await recordAudit(store, {
    actorType: "STAFF",
    actorId: actor.id,
    action,
    entityType: "quote",
    entityId: quoteId,
    ...(after !== undefined ? { after } : {}),
    ...(actor.ip ? { ip: actor.ip } : {}),
    ...(actor.userAgent ? { userAgent: actor.userAgent } : {}),
  });
}

type LineShape = {
  lineKind: string;
  billing: string | null;
  frequency: string | null;
  description: string;
  amountCents: number | null;
};

function sameLines(existing: LineShape[], next: LineShape[]): boolean {
  return (
    existing.length === next.length &&
    existing.every((l, i) => {
      const n = next[i];
      return (
        n !== undefined &&
        l.lineKind === n.lineKind &&
        l.billing === n.billing &&
        l.frequency === n.frequency &&
        l.description === n.description &&
        l.amountCents === n.amountCents
      );
    })
  );
}

/**
 * Saves the whole draft in one go (scope switches, price lines, valid-until date, internal note).
 * `input.version` must be the version the browser last saw. A save that changes nothing writes
 * nothing and returns the same version. Drafts are not audited.
 */
export async function saveDraft(
  store: QuoteStore,
  actor: Actor,
  id: string,
  input: DraftInput,
): Promise<{ version: number }> {
  assertRole(actor, MANAGEMENT);
  const read = async () => {
    const quote = await findQuote(store, id);
    if (quote.status !== "DRAFT") throw new DomainError("Only a draft can be changed.");
    if (quote.draftVersion !== input.version) throw new DraftConflictError();
    return quote;
  };
  const lines = input.lines.map(normaliseLine);

  // Look first WITHOUT locking: a save that changes nothing must write nothing.
  const first = await read();
  const known = new Set(first.scopeItems.map((s) => s.serviceId));
  if (input.scope.some((s) => !known.has(s.serviceId))) {
    throw new DomainError("That service is not on this quote.");
  }
  const flags = new Map(input.scope.map((s) => [s.serviceId, s.included]));
  const same =
    toDateString(first.validUntil) === input.validUntil &&
    (first.internalNote ?? "") === input.internalNote &&
    first.scopeItems.every((s) => !flags.has(s.serviceId) || flags.get(s.serviceId) === s.included) &&
    sameLines(first.lines, lines);
  if (same) return { version: first.draftVersion };

  await lockQuote(store, id);
  const quote = await read();
  for (const item of quote.scopeItems) {
    const included = flags.get(item.serviceId);
    if (included !== undefined && included !== item.included) {
      await store.quoteScopeItem.update({ where: { id: item.id }, data: { included } });
    }
  }
  await store.quoteLine.deleteMany({ where: { quoteId: id } });
  if (lines.length > 0) {
    await store.quoteLine.createMany({
      data: lines.map((l, index) => ({
        quoteId: id,
        sortOrder: index + 1,
        lineKind: l.lineKind,
        billing: l.billing,
        frequency: l.frequency,
        description: l.description,
        amountCents: l.amountCents,
      })),
    });
  }
  const updated = await store.quote.update({
    where: { id },
    data: {
      validUntil: fromDateString(input.validUntil),
      internalNote: input.internalNote === "" ? null : input.internalNote,
      draftVersion: { increment: 1 },
    },
    select: { draftVersion: true },
  });
  return { version: updated.draftVersion };
}

/** Only a quote that was never issued can be deleted. */
export async function deleteDraft(store: QuoteStore, actor: Actor, id: string): Promise<void> {
  assertRole(actor, MANAGEMENT);
  if ((await findQuote(store, id)).status !== "DRAFT") {
    throw new DomainError("Only a draft can be deleted.");
  }
  await lockQuote(store, id);
  if ((await findQuote(store, id)).status !== "DRAFT") {
    throw new DomainError("Only a draft can be deleted.");
  }
  await store.quoteLine.deleteMany({ where: { quoteId: id } });
  await store.quoteScopeItem.deleteMany({ where: { quoteId: id } });
  await store.quote.delete({ where: { id } });
  await logQuoteEvent(store, actor, "quote.deleted_draft", id);
}

export const QUOTE_FILTERS = [
  "DRAFT",
  "ISSUED",
  "EXPIRED",
  "ACCEPTED",
  "DECLINED",
  "REPLACED",
  "WITHDRAWN",
] as const;

export type QuoteListQuery = {
  status?: string | undefined;
  q?: string | undefined;
  customerId?: string | undefined;
  page?: number | undefined;
  pageSize?: number | undefined;
};

function buildWhere(query: QuoteListQuery, today: string): Prisma.QuoteWhereInput {
  const and: Prisma.QuoteWhereInput[] = [];
  if (query.customerId) and.push({ customerId: query.customerId });
  const status = QUOTE_FILTERS.find((f) => f === query.status);
  const todayDate = fromDateString(today);
  if (status === "EXPIRED") and.push({ status: "ISSUED", validUntil: { lt: todayDate } });
  else if (status === "ISSUED") and.push({ status: "ISSUED", validUntil: { gte: todayDate } });
  else if (status) and.push({ status });

  const term = query.q?.trim();
  if (term) {
    const or: Prisma.QuoteWhereInput[] = [
      { customer: { displayName: { contains: term, mode: "insensitive" } } },
    ];
    const ref = /^(?:quo-)?(?:(\d{4})-)?(\d{1,6})$/i.exec(term);
    if (ref?.[2]) {
      or.push({
        numberSeq: Number(ref[2]),
        ...(ref[1] ? { numberYear: Number(ref[1]) } : {}),
      });
    }
    and.push({ OR: or });
  }
  return { AND: and };
}

function clampInt(value: unknown, min: number, max: number, fallback: number): number {
  const whole = typeof value === "number" && Number.isFinite(value) ? Math.floor(value) : fallback;
  return Math.min(max, Math.max(min, whole));
}

export async function listQuotes(store: QuoteStore, actor: Actor, query: QuoteListQuery) {
  assertRole(actor, MANAGEMENT);
  const pageSize = clampInt(query.pageSize, 1, 100, 25);
  const page = clampInt(query.page, 1, 10_000, 1);
  const today = todaySA();
  const where = buildWhere(query, today);
  const rows = await store.quote.findMany({
    where,
    orderBy: [{ createdAt: "desc" }, { id: "desc" }],
    skip: (page - 1) * pageSize,

import { assertRole, DomainError, MANAGEMENT, type Actor } from "../customers/access";
import type { Prisma } from "../generated/prisma/client";
import { contentHash } from "./content";
import {
  addDays,
  formatQuoteReference,
  fromDateString,
  toDateString,
  todaySA,
  yearSA,
} from "./reference";
import { validateForIssue } from "./schemas";
import { findQuote, lockQuote, logQuoteEvent, requireQuotable, type QuoteStore } from "./store";
import { readQuoteWording } from "./wording";
import { snapshotWording } from "./wording-schema";

type SentMethod = "WHATSAPP" | "EMAIL" | "HAND" | "OTHER";

/** An incomplete quote cannot be issued. `problems` are plain sentences; the message joins them. */
export class QuoteIssueError extends DomainError {
  readonly problems: string[];
  constructor(problems: string[]) {
    super(problems.join("\n"));
    this.name = "QuoteIssueError";
    this.problems = problems;
  }
}

/** The next running number for the year, taken with one atomic statement (no repeats, no gaps). */
export async function allocateQuoteNumber(store: QuoteStore, year: number): Promise<number> {
  const rows = await store.$queryRaw<{ lastSeq: number }[]>`
    insert into quote_counters ("year", "lastSeq") values (${year}, 1)
    on conflict ("year") do update set "lastSeq" = quote_counters."lastSeq" + 1
    returning "lastSeq"`;
  const seq = rows[0]?.lastSeq;
  if (seq === undefined) throw new Error("Could not allocate a quote number.");
  return Number(seq);
}

const SERVICE_ORDER: Prisma.ServiceOrderByWithRelationInput[] = [
  { sortOrder: "asc" },
  { createdAt: "asc" },
  { id: "asc" },
];

/**
 * Brings the quote's scope up to date with the catalogue just before issuing: every active service
 * appears (new ones as Not included), a switched-off service stays only if it was included, and
 * every row takes the catalogue's current wording and order.
 */
async function refreshScope(store: QuoteStore, quote: Awaited<ReturnType<typeof findQuote>>) {
  const services = await store.service.findMany({ orderBy: SERVICE_ORDER });
  const existing = new Map(quote.scopeItems.map((s) => [s.serviceId, s]));
  const keep = services.filter((s) => !s.archivedAt || existing.get(s.id)?.included);
  const keepIds = new Set(keep.map((s) => s.id));
  for (const item of quote.scopeItems) {
    if (!keepIds.has(item.serviceId)) {
      await store.quoteScopeItem.delete({ where: { id: item.id } });
    }
  }
  for (const [index, service] of keep.entries()) {
    const item = existing.get(service.id);
    const wording = {
      sortOrder: index + 1,
      name: service.name,
      description: service.description,
      kind: service.kind,
    };
    if (!item) {
      await store.quoteScopeItem.create({
        data: { quoteId: quote.id, serviceId: service.id, included: false, ...wording },
      });
    } else if (
      item.sortOrder !== wording.sortOrder ||
      item.name !== wording.name ||
      item.description !== wording.description ||
      item.kind !== wording.kind
    ) {
      await store.quoteScopeItem.update({ where: { id: item.id }, data: wording });
    }
  }
}

/** Finish: validates, gives the number, and freezes the content, wording and recipient. */
export async function issueQuote(
  store: QuoteStore,
  actor: Actor,
  id: string,
): Promise<{ id: string; reference: string }> {
  assertRole(actor, MANAGEMENT);
  if ((await findQuote(store, id)).status !== "DRAFT") {
    throw new DomainError("Only a draft can be issued.");
  }
  await lockQuote(store, id);
  const quote = await findQuote(store, id);
  if (quote.status !== "DRAFT") throw new DomainError("Only a draft can be issued.");

  const { property } = await requireQuotable(store, quote.customerId, quote.propertyId);
  await refreshScope(store, quote);
  const scope = await store.quoteScopeItem.findMany({
    where: { quoteId: id },
    orderBy: { sortOrder: "asc" },
  });
  const validUntil = toDateString(quote.validUntil);
  const problems = validateForIssue({ validUntil, scope, lines: quote.lines }, todaySA());
  if (problems.length > 0) throw new QuoteIssueError(problems);

  let numberYear: number | null;
  let numberSeq: number | null;
  if (quote.revisionOfId) {
    const source = await store.quote.findUniqueOrThrow({
      where: { id: quote.revisionOfId },
      select: { numberYear: true, numberSeq: true },
    });
    ({ numberYear, numberSeq } = source);
  } else {
    numberYear = yearSA();
    numberSeq = await allocateQuoteNumber(store, numberYear);
  }
  if (numberYear === null || numberSeq === null) {
    throw new DomainError("The quote this revises has no number.");
  }

  const contacts = await store.contact.findMany({
    where: { customerId: quote.customerId },
    orderBy: { createdAt: "asc" },
  });
  const contact = contacts.find((c) => c.receivesQuotes) ?? contacts[0];
  if (!contact) throw new DomainError("This customer has no contact to address the quote to.");
  const siteAddress = [property.addressLine1, property.addressLine2, property.suburb, property.city]
    .filter(Boolean)
    .join(", ");

  const org = await store.organisationSettings.findUniqueOrThrow({ where: { id: "singleton" } });
  const snapshot = snapshotWording(await readQuoteWording(store), quote.lines, org);
  const recipient = { name: contact.name, email: contact.email, phone: contact.phone };
  const hash = contentHash({
    reference: { year: numberYear, seq: numberSeq, revision: quote.revision },
    validUntil,
    recipient,
    site: { label: property.label, address: siteAddress },
    scope: scope.map((s) => ({
      serviceId: s.serviceId,
      name: s.name,
      description: s.description,
      kind: s.kind,
      included: s.included,
    })),
    lines: quote.lines.map((l) => ({
      lineKind: l.lineKind,
      billing: l.billing,
      frequency: l.frequency,
      description: l.description,
      amountCents: l.amountCents,
    })),
    wording: snapshot,
  });

  await store.quote.update({
    where: { id },
    data: {
      status: "ISSUED",
      numberYear,
      numberSeq,
      issuedAt: new Date(),
      issuedById: actor.id,
      recipientName: recipient.name,
      recipientEmail: recipient.email,
      recipientPhone: recipient.phone,
      siteLabel: property.label,
      siteAddress,
      wordingSnapshot: snapshot as unknown as Prisma.InputJsonValue,
      contentHash: hash,
    },
  });

  if (quote.revisionOfId) {
    const previous = await store.quote.findUnique({
      where: { id: quote.revisionOfId },
      select: { id: true, status: true },
    });
    if (previous?.status === "ISSUED") {
      await store.quote.update({ where: { id: previous.id }, data: { status: "REPLACED" } });
      await logQuoteEvent(store, actor, "quote.replaced", previous.id);
    }
  }
  await logQuoteEvent(store, actor, "quote.issued", id, { revision: quote.revision });
  return {
    id,
    reference: formatQuoteReference({ numberYear, numberSeq, revision: quote.revision }) ?? "",
  };
}

/** Copies an issued, accepted or declined quote into a new draft that revises it. */
export async function reviseQuote(
  store: QuoteStore,
  actor: Actor,
  id: string,
): Promise<{ id: string }> {
  assertRole(actor, MANAGEMENT);
  const allowed = ["ISSUED", "ACCEPTED", "DECLINED"];
  if (!allowed.includes((await findQuote(store, id)).status)) {
    throw new DomainError("This quote cannot be revised.");
  }
  await lockQuote(store, id);
  const source = await findQuote(store, id);
  if (!allowed.includes(source.status)) throw new DomainError("This quote cannot be revised.");
  const open = await store.quote.findFirst({
    where: { revisionOfId: id, status: "DRAFT" },
    select: { id: true },
  });
  if (open) throw new DomainError("There is already a draft revision of this quote.");

  const latest = await store.quote.aggregate({
    where: { numberYear: source.numberYear, numberSeq: source.numberSeq },
    _max: { revision: true },
  });
  const wording = await readQuoteWording(store);
  const created = await store.quote.create({
    data: {
      customerId: source.customerId,
      propertyId: source.propertyId,
      createdById: actor.id,
      revisionOfId: source.id,
      revision: (latest._max.revision ?? source.revision) + 1,
      validUntil: fromDateString(addDays(todaySA(), wording.defaultValidityDays)),
      internalNote: source.internalNote,
      scopeItems: {
        create: source.scopeItems.map((s) => ({
          serviceId: s.serviceId,
          sortOrder: s.sortOrder,
          included: s.included,
          name: s.name,
          description: s.description,
          kind: s.kind,
        })),
      },
      lines: {
        create: source.lines.map((l) => ({
          sortOrder: l.sortOrder,
          lineKind: l.lineKind,
          billing: l.billing,
          frequency: l.frequency,
          description: l.description,
          amountCents: l.amountCents,
        })),
      },
    },
    select: { id: true },
  });
  await logQuoteEvent(store, actor, "quote.revised", created.id, { from: source.id });
  return created;
}

export async function withdrawQuote(store: QuoteStore, actor: Actor, id: string): Promise<void> {
  assertRole(actor, MANAGEMENT);
  if ((await findQuote(store, id)).status !== "ISSUED") {
    throw new DomainError("Only an issued quote can be withdrawn.");
  }
  await lockQuote(store, id);
  if ((await findQuote(store, id)).status !== "ISSUED") {
    throw new DomainError("Only an issued quote can be withdrawn.");
  }
  await store.quote.update({
    where: { id },
    data: { status: "WITHDRAWN", withdrawnAt: new Date() },
  });
  await logQuoteEvent(store, actor, "quote.withdrawn", id);
}

/** Records that staff shared the quote (copy and paste, or the PDF). Nothing is sent by the app. */
export async function markSent(
  store: QuoteStore,
  actor: Actor,
  id: string,
  method: SentMethod,
): Promise<void> {
  assertRole(actor, MANAGEMENT);
  if ((await findQuote(store, id)).status !== "ISSUED") {
    throw new DomainError("Only an issued quote can be marked as sent.");
  }
  await lockQuote(store, id);
  await store.quote.update({ where: { id }, data: { sentAt: new Date(), sentMethod: method } });
  await logQuoteEvent(store, actor, "quote.sent", id, { method });
}

import { assertRole, DomainError, MANAGEMENT, OWNER_ONLY, type Actor } from "../customers/access";
import { activateCustomer } from "../customers/customers";
import type { Prisma } from "../generated/prisma/client";
import { displayStatus, formatQuoteReference, fromDateString, todaySA } from "./reference";
import type { AcceptInput, DeclineInput } from "./schemas";
import { findQuote, lockQuote, logQuoteEvent, type QuoteStore } from "./store";
import { acceptedTotals } from "./totals";

/** A monthly agreement means a priced monthly line, or an optional monthly line the client chose. */
const MONTHLY_AGREEMENT: Prisma.QuoteLineWhereInput = {
  billing: "MONTHLY",
  OR: [{ lineKind: "PRICED" }, { lineKind: "OPTIONAL", chosen: true }],
};
const ONCE_OFF_AGREEMENT: Prisma.QuoteLineWhereInput = {
  billing: "ONCE_OFF",
  OR: [{ lineKind: "PRICED" }, { lineKind: "OPTIONAL", chosen: true }],
};

export async function acceptQuote(
  store: QuoteStore,
  actor: Actor,
  id: string,
  input: AcceptInput,
): Promise<{ customerFlag: "PAUSED" | "ARCHIVED" | null }> {
  assertRole(actor, MANAGEMENT);
  const check = (q: Awaited<ReturnType<typeof findQuote>>) => {
    if (q.status !== "ISSUED") throw new DomainError("Only an issued quote can be accepted.");
    if (displayStatus(q) === "EXPIRED") {
      throw new DomainError("This quote has expired. Revise it to give it new dates.");
    }
  };
  check(await findQuote(store, id));
  await lockQuote(store, id);
  const quote = await findQuote(store, id);
  check(quote);
  if (input.startDate < todaySA()) throw new DomainError("The start date must be today or later.");
  const optionalIds = new Set(
    quote.lines.filter((l) => l.lineKind === "OPTIONAL").map((l) => l.id),
  );
  if (input.chosenLineIds.some((lineId) => !optionalIds.has(lineId))) {
    throw new DomainError("Only optional add-ons can be chosen.");
  }

  await store.quoteLine.updateMany({
    where: { quoteId: id, id: { in: input.chosenLineIds } },
    data: { chosen: true },
  });
  await store.quote.update({
    where: { id },
    data: {
      status: "ACCEPTED",
      acceptedAt: new Date(),
      acceptedMethod: input.method,
      acceptedByName: input.acceptedBy,
      acceptedStartDate: fromDateString(input.startDate),
      acceptanceNote: input.note ?? null,
      acceptedByStaffId: actor.id,
    },
  });

  // Agreement rule: a newly accepted monthly quote replaces the property's earlier monthly agreement.
  const isMonthly = quote.lines.some(
    (l) =>
      l.billing === "MONTHLY" &&
      (l.lineKind === "PRICED" ||
        (l.lineKind === "OPTIONAL" && input.chosenLineIds.includes(l.id))),
  );
  if (isMonthly) {
    const earlier = await store.quote.findMany({
      where: {
        propertyId: quote.propertyId,
        status: "ACCEPTED",
        agreementEndedAt: null,
        id: { not: id },
        lines: { some: MONTHLY_AGREEMENT },
      },
      select: { id: true },
    });
    for (const old of earlier) {
      await store.quote.update({
        where: { id: old.id },
        data: { agreementEndedAt: new Date(), agreementReplacedById: id },
      });
      await logQuoteEvent(store, actor, "quote.agreement_ended", old.id, { replacedBy: id });
    }
  }

  // A lead becomes active. A paused or archived customer is left alone and flagged to staff.
  const customer = await store.customer.findUniqueOrThrow({
    where: { id: quote.customerId },
    select: { status: true },
  });
  let customerFlag: "PAUSED" | "ARCHIVED" | null = null;
  if (customer.status === "LEAD") {
    await activateCustomer(store, actor, quote.customerId, { via: "quote" });
  } else if (customer.status === "PAUSED" || customer.status === "ARCHIVED") {
    customerFlag = customer.status;
  }

  await logQuoteEvent(store, actor, "quote.accepted", id, {
    method: input.method,
    optionsChosen: input.chosenLineIds.length,
    customerFlag,
  });
  return { customerFlag };
}

export async function declineQuote(
  store: QuoteStore,
  actor: Actor,
  id: string,
  input: DeclineInput,
): Promise<void> {
  assertRole(actor, MANAGEMENT);
  if ((await findQuote(store, id)).status !== "ISSUED") {
    throw new DomainError("Only an issued quote can be declined.");
  }
  await lockQuote(store, id);
  if ((await findQuote(store, id)).status !== "ISSUED") {
    throw new DomainError("Only an issued quote can be declined.");
  }
  await store.quote.update({
    where: { id },
    data: { status: "DECLINED", declinedAt: new Date(), declineReason: input.reason ?? null },
  });
  await logQuoteEvent(store, actor, "quote.declined", id);
}

/** Owner only. Puts an accepted quote back to issued; the customer's status is not touched. */
export async function reverseAcceptance(
  store: QuoteStore,
  actor: Actor,
  id: string,
  note: string,
): Promise<void> {
  assertRole(actor, OWNER_ONLY);
  const text = note.trim();
  if (!text) throw new DomainError("Say why the acceptance is being reversed.");
  if (text.length > 300) throw new DomainError("Keep the reason under 300 characters.");
  const check = (q: Awaited<ReturnType<typeof findQuote>>) => {
    if (q.status !== "ACCEPTED") throw new DomainError("Only an accepted quote can be reversed.");
    if (q.agreementEndedAt) {
      throw new DomainError("A later quote has replaced this agreement. Reverse that one first.");
    }
  };
  check(await findQuote(store, id));
  await lockQuote(store, id);
  check(await findQuote(store, id));

  await store.quoteLine.updateMany({ where: { quoteId: id }, data: { chosen: false } });
  await store.quote.update({
    where: { id },
    data: {
      status: "ISSUED",
      acceptedAt: null,
      acceptedMethod: null,
      acceptedByName: null,
      acceptedStartDate: null,
      acceptanceNote: null,
      acceptedByStaffId: null,
      acceptedIp: null,
      acceptedUserAgent: null,
      reversedAt: new Date(),
      reversalNote: text,
    },
  });
  // Any agreement this quote had ended is restored.
  await store.quote.updateMany({
    where: { agreementReplacedById: id },
    data: { agreementEndedAt: null, agreementReplacedById: null },
  });
  await logQuoteEvent(store, actor, "quote.reversed", id);
}

const AGREEMENT_SELECT = {
  id: true,
  numberYear: true,
  numberSeq: true,
  revision: true,
  acceptedAt: true,
  acceptedStartDate: true,
  scopeItems: {
    where: { included: true },
    orderBy: { sortOrder: "asc" },
    select: { id: true, name: true, description: true, kind: true },
  },
  lines: {
    orderBy: { sortOrder: "asc" },
    select: {
      id: true,
      lineKind: true,
      billing: true,
      frequency: true,
      description: true,
      amountCents: true,
      chosen: true,
    },
  },
} as const satisfies Prisma.QuoteSelect;

type AgreementRow = Prisma.QuoteGetPayload<{ select: typeof AGREEMENT_SELECT }>;

function toAgreement(row: AgreementRow) {
  return {
    id: row.id,
    reference: formatQuoteReference(row),
    acceptedAt: row.acceptedAt,
    acceptedStartDate: row.acceptedStartDate,
    scope: row.scopeItems,
    lines: row.lines.filter((l) => l.lineKind !== "OPTIONAL" || l.chosen),
    totals: acceptedTotals(row.lines),
  };
}

/**
 * The property's agreed scope: its current monthly agreement and its accepted once-off quotes. A
 * quote with both monthly and once-off work is the monthly agreement and is not listed twice; a
 * monthly agreement that a later one replaced is no longer shown.
 */
export async function getPropertyAgreement(store: QuoteStore, actor: Actor, propertyId: string) {
  assertRole(actor, MANAGEMENT);
  const current = await store.quote.findFirst({
    where: {
      propertyId,
      status: "ACCEPTED",
      agreementEndedAt: null,
      lines: { some: MONTHLY_AGREEMENT },
    },
    orderBy: [{ acceptedAt: "desc" }, { id: "desc" }],
    select: AGREEMENT_SELECT,
  });
  const onceOff = await store.quote.findMany({
    where: {
      propertyId,
      status: "ACCEPTED",
      agreementEndedAt: null,
      lines: { some: ONCE_OFF_AGREEMENT },
      ...(current ? { id: { not: current.id } } : {}),
    },
    orderBy: [{ acceptedAt: "desc" }, { id: "desc" }],
    select: AGREEMENT_SELECT,
  });
  return { current: current ? toAgreement(current) : null, onceOff: onceOff.map(toAgreement) };
}

export async function quickAddQuoteAction(
  _prev: FormState,
  formData: FormData,
): Promise<FormState> {
  const staff = await requireStaff(MANAGEMENT);
  const actor = await toActor(staff);
  const values = formValues(formData);

  const customer = customerSchema.safeParse({
    type: values.type,
    displayName: values.displayName,
    status: "LEAD",
  });
  const contact = contactSchema.safeParse({
    name: values.displayName,
    email: values.email,
    phone: values.phone,
    receivesQuotes: "on",
    receivesInvoices: "on",
  });
  const property = propertySchema.safeParse({
    label: "Main property",
    addressLine1: values.addressLine1,
    suburb: values.suburb,
    city: values.city,
  });
  if (!customer.success || !contact.success || !property.success) {
    const customerErrors: Record<string, string> = customer.success
      ? {}
      : errorsFrom(customer.error);
    const { name: nameError, ...otherContactErrors } = contact.success
      ? ({} as Record<string, string>)
      : errorsFrom(contact.error);
    const fieldErrors: Record<string, string> = {
      ...customerErrors,
      ...otherContactErrors,
      ...(property.success ? {} : errorsFrom(property.error)),
    };
    // The contact's name is the prospect's name, so a name problem belongs to that one box.
    const displayNameError = customerErrors.displayName ?? nameError;
    if (displayNameError) fieldErrors.displayName = displayNameError;
    return { fieldErrors, values, nonce: Date.now() };
  }

  let id: string;
  try {
    const result = await inTx(async (tx) => {
      // A warning, not a block: the same email or phone on another customer.
      if (values.confirmDuplicates !== "1") {
        const duplicates = await findDuplicateContacts(tx, actor, {
          emails: contact.data.email ? [contact.data.email] : [],
          phones: contact.data.phone ? [contact.data.phone] : [],
        });
        if (duplicates.length > 0) return { duplicates } as const;
      }
      const created = await createCustomer(tx, actor, {
        customer: customer.data,
        contact: contact.data,
        property: property.data,
      });
      const site = await tx.property.findFirstOrThrow({ where: { customerId: created.id } });
      const quote = await createQuote(tx, actor, { customerId: created.id, propertyId: site.id });
      return { id: quote.id } as const;
    });
    if ("duplicates" in result) return { duplicates: result.duplicates, values, nonce: Date.now() };
    id = result.id;
  } catch (error) {
    return failure(error, values);
  }
  redirect(`/quotes/${id}`);
}

import { assertRole, MANAGEMENT, type Actor } from "../customers/access";
import type { QuoteStore } from "./store";

export async function listQuoteActivity(store: QuoteStore, actor: Actor, id: string, limit = 100) {
  assertRole(actor, MANAGEMENT);
  const entries = await store.auditLog.findMany({
    where: { entityType: "quote", entityId: id },
    orderBy: { at: "desc" },
    take: limit,
    select: { id: true, at: true, action: true, actorId: true, after: true },
  });
  const ids = [...new Set(entries.map((e) => e.actorId).filter((v): v is string => Boolean(v)))];
  const staff = await store.staffUser.findMany({
    where: { id: { in: ids } },
    select: { id: true, name: true },
  });
  const names = new Map(staff.map((s) => [s.id, s.name]));
  return entries.map((e) => ({
    ...e,
    actorName: e.actorId ? (names.get(e.actorId) ?? "Staff") : "System",
  }));
}

type Quote = NonNullable<Awaited<ReturnType<typeof getQuote>>>;

/**
 * Builds the document for a stored quote. An issued (or later) quote uses its frozen recipient and
 * wording; a draft is built from the live customer, property and standard wording.
 */
export async function loadDocument(quote: Quote, actor: Actor) {
  const frozen = quote.status !== "DRAFT";
  const lines = quote.lines.map((l) => ({
    id: l.id,
    lineKind: l.lineKind,
    billing: l.billing,
    frequency: l.frequency,
    description: l.description,
    amountCents: l.amountCents,
    chosen: l.chosen,
  }));
  const scope = quote.scopeItems.map((s) => ({
    name: s.name,
    description: s.description,
    kind: s.kind,
    included: s.included,
  }));

  let wording;
  let preparedFor;
  if (frozen) {
    wording = wordingSnapshotSchema.parse(quote.wordingSnapshot);
    preparedFor = {
      name: quote.recipientName ?? "Anonymised customer",
      email: quote.recipientEmail,
      phone: quote.recipientPhone,
      siteLabel: quote.siteLabel ?? "",
      siteAddress: quote.siteAddress ?? "",
    };
  } else {
    const db = getDb();
    const org = await db.organisationSettings.findUniqueOrThrow({ where: { id: "singleton" } });
    wording = snapshotWording(await getQuoteWording(db, actor), lines, org);
    const customer = await getCustomer(db, actor, quote.customerId);
    const contact =
      customer?.contacts.find((c) => c.receivesQuotes) ?? customer?.contacts[0] ?? null;
    preparedFor = {
      name: contact?.name ?? quote.customer.displayName,
      email: contact?.email ?? null,
      phone: contact?.phone ?? null,
      siteLabel: quote.property.label,
      siteAddress: [
        quote.property.addressLine1,
        quote.property.addressLine2,
        quote.property.suburb,
        quote.property.city,
      ]
        .filter(Boolean)
        .join(", "),
    };
  }

  const doc = buildQuoteDocument({
    status: displayStatus(quote),
    reference: formatQuoteReference(quote),
    issuedDate: quote.issuedAt ? formatDate(quote.issuedAt) : null,
    validUntil: formatDate(quote.validUntil),
    preparedFor,
    scope,
    lines,
    wording,
  });
  return { doc, frozen };
}

type SaveResult =
  | { ok: true; version: number }
  | { ok: false; conflict: boolean; error: string };

/** Called by the builder about 800 ms after the last change. `payload` is a DraftInput as JSON. */
export async function saveDraftAction(quoteId: string, payload: string): Promise<SaveResult> {
  const staff = await requireStaff(MANAGEMENT);
  const actor = await toActor(staff);
  const id = idSchema.safeParse(quoteId);
  if (!id.success) return { ok: false, conflict: false, error: "Refresh the page and try again." };
  let raw: unknown;
  try {
    raw = JSON.parse(payload);
  } catch {
    return { ok: false, conflict: false, error: "Refresh the page and try again." };
  }
  const parsed = draftSchema.safeParse(raw);
  if (!parsed.success) {
    return {
      ok: false,
      conflict: false,
      error: parsed.error.issues[0]?.message ?? "Some details are not valid.",
    };
  }
  try {
    const { version } = await inTx((tx) => saveDraft(tx, actor, id.data, parsed.data));
    return { ok: true, version };
  } catch (error) {
    if (error instanceof DraftConflictError) {
      return { ok: false, conflict: true, error: error.message };
    }
    const state = failure(error); // a refused role redirects; anything unexpected is rethrown
    return { ok: false, conflict: false, error: state?.error ?? "Could not save." };
  }
}

/** Finish and issue. An incomplete quote comes back as a list of problems, one per line. */
export async function issueQuoteAction(_prev: FormState, formData: FormData): Promise<FormState> {
  const staff = await requireStaff(MANAGEMENT);
  const actor = await toActor(staff);
  const id = idSchema.safeParse(formData.get("id"));
  if (!id.success) return { error: "Something went wrong. Refresh the page and try again." };
  try {
    await inTx((tx) => issueQuote(tx, actor, id.data));
  } catch (error) {
    return failure(error);
  }
  redirect(`/quotes/${id.data}`);
}

export async function deleteDraftAction(formData: FormData): Promise<void> {
  const staff = await requireStaff(MANAGEMENT);
  const actor = await toActor(staff);
  const id = idSchema.parse(formData.get("id"));
  try {
    await inTx((tx) => deleteDraft(tx, actor, id));
  } catch (error) {
    failure(error);
  }
  redirect("/quotes");
}

/** Rand text to cents. Blank, invalid, zero or too large all give null (the form shows a message). */

  const t = text.trim();
  if (t === "") return null;
  const cents = parseRandToCents(t);

}

/** Switching the kind keeps the other settings sensible: included lines are free, add-ons are "as required". */
export function withKind(line: BuilderLine, kind: LineKind): BuilderLine {
  if (kind === "INCLUDED") {
    return { ...line, lineKind: kind, billing: null, frequency: null, amountText: "" };
  }
  return withBilling({ ...line, lineKind: kind }, line.billing ?? "MONTHLY");
}

export function withBilling(line: BuilderLine, billing: Billing): BuilderLine {
  if (billing === "ONCE_OFF") return { ...line, billing, frequency: null };
  const fallback: Frequency = line.lineKind === "OPTIONAL" ? "AS_REQUIRED" : "WEEKLY";
  const current = line.frequency ?? fallback;
  const frequency = current === "AS_REQUIRED" && line.lineKind === "PRICED" ? "WEEKLY" : current;
  return { ...line, billing, frequency };
}

      lineKind: l.lineKind,
      billing: l.billing,
      frequency: l.frequency,
      description: l.description,
      amountCents: parseAmount(l.amountText),
    })),
  };
}

const BILLING_OPTIONS = LINE_BILLINGS.map((b) => ({ value: b, label: BILLING_LABELS[b] }));

function frequencyOptions(line: BuilderLine): { value: Frequency; label: string }[] {
  const all: Frequency[] =
    line.lineKind === "OPTIONAL"
      ? ["WEEKLY", "FORTNIGHTLY", "MONTHLY", "AS_REQUIRED"]
      : ["WEEKLY", "FORTNIGHTLY", "MONTHLY"];
  return all.map((f) => ({ value: f, label: FREQUENCY_LABELS[f] }));
}

export function LinesStep({
  lines,
  suggestMonthly,
  onChange,
}: {
  lines: BuilderLine[];
  suggestMonthly: boolean;
  onChange: (lines: BuilderLine[]) => void;
}) {
  const update = (index: number, next: BuilderLine) =>
    onChange(lines.map((l, i) => (i === index ? next : l)));
  const move = (index: number, delta: number) => {
    const target = index + delta;
    if (target < 0 || target >= lines.length) return;
    const copy = [...lines];
    const a = copy[index];
    const b = copy[target];
    if (!a || !b) return;
    copy[index] = b;
    copy[target] = a;
    onChange(copy);
  };

  return (
    <div>
      <p className="text-sm text-charcoal/70">
        One combined price for the standard services, and a separate line for anything optional, such
        as weed treatment.
      </p>

      {suggestMonthly ? (
        <div className="mt-4 rounded-xl bg-ochre/10 p-4 ring-1 ring-ochre/30">
          <p className="text-sm text-charcoal">
            You have services switched on but no monthly price yet.
          </p>
          <button
            type="button"
            className={`${buttonSmall} mt-2`}
            onClick={() =>
              onChange([
                ...lines,
                blankLine({ description: "Garden maintenance, as per scope", frequency: "WEEKLY" }),
              ])
            }
          >
            Add the monthly line
          </button>
        </div>
      ) : null}

      <ul className="mt-4 space-y-4">
        {lines.map((l, index) => {
          const problem = amountProblem(l.amountText);
          return (
            <li key={l.key} className="space-y-3 rounded-2xl bg-white/70 p-4 ring-1 ring-charcoal/10">
              <p className="text-xs font-semibold uppercase tracking-wide text-charcoal/50">
                Line {index + 1}
              </p>
              <Chips<LineKind>
                label={`Line ${index + 1} type`}
                value={l.lineKind}
                options={KIND_OPTIONS}
                onChange={(k) => update(index, withKind(l, k))}
              />
              {l.lineKind !== "INCLUDED" ? (
                <Chips<Billing>
                  label={`Line ${index + 1} billing`}
                  value={l.billing}
                  options={BILLING_OPTIONS}
                  onChange={(b) => update(index, withBilling(l, b))}
                />
              ) : null}
              {l.lineKind !== "INCLUDED" && l.billing === "MONTHLY" ? (
                <Chips<Frequency>
                  label={`Line ${index + 1} how often`}
                  value={l.frequency}
                  options={frequencyOptions(l)}
                  onChange={(f) => update(index, { ...l, frequency: f })}
                />
              ) : null}
              <label className="block text-sm font-medium text-charcoal">
                Description
                <input
                  value={l.description}
                  maxLength={300}
                  onChange={(e) => update(index, { ...l, description: e.target.value })}
                  className={inputClass}
                />
              </label>
              {l.lineKind !== "INCLUDED" ? (
                <label className="block text-sm font-medium text-charcoal">
                  Amount (R)
                  <input
                    value={l.amountText}
                    inputMode="decimal"
                    onChange={(e) => update(index, { ...l, amountText: e.target.value })}
                    aria-invalid={problem ? true : undefined}
                    className={inputClass}
                  />
                  {problem ? (
                    <span role="alert" className="mt-1 block text-xs font-normal text-red-700">
                      {problem}
                    </span>
                  ) : (
                    <span className="mt-1 block text-xs font-normal text-charcoal/60">
                      {l.billing === "MONTHLY" ? "Per month. " : ""}e.g. 850 or 1150.50
                    </span>
                  )}
                </label>
              ) : null}
              <div className="flex flex-wrap gap-2">
                <button
                  type="button"
                  className={buttonSmall}
                  disabled={index === 0}
                  onClick={() => move(index, -1)}
                  aria-label={`Move line ${index + 1} up`}
                >
                  ↑
                </button>
                <button
                  type="button"
                  className={buttonSmall}
                  disabled={index === lines.length - 1}
                  onClick={() => move(index, 1)}
                  aria-label={`Move line ${index + 1} down`}
                >
                  ↓
                </button>
                <button
                  type="button"
                  className={buttonSmall}
                  onClick={() => onChange(lines.filter((_, i) => i !== index))}
                  aria-label={`Remove line ${index + 1}`}
                >
                  Remove
                </button>
              </div>
            </li>
          );
        })}
      </ul>

      <button type="button" className={`${buttonSmall} mt-4`} onClick={() => onChange([...lines, blankLine()])}>
        Add price line
      </button>
    </div>
  );
}

"use client";

import {
  buildQuoteDocument,
  snapshotWording,
  validateForIssue,
} from "@ace/core/client";
import Link from "next/link";
import { useActionState, useCallback, useEffect, useMemo, useRef, useState } from "react";
import { buttonClass } from "@/components/auth-card";
import { formatDate } from "@/lib/format";
import { deleteDraftAction, issueQuoteAction, saveDraftAction } from "../actions";
import {
  blankLine,
  parseAmount,
  toPayload,
  type BuilderInitial,
  type BuilderState,
} from "./builder-types";
import { DetailsStep, LinesStep, ScopeStep, TotalsSummary } from "./builder-parts";
import { QuoteDocumentView } from "./quote-document";

const STEPS = ["Scope", "Prices", "Details", "Review"] as const;

export function QuoteBuilder({ initial }: { initial: BuilderInitial }) {
  const [state, setState] = useState<BuilderState>(initial.state);
  const [step, setStep] = useState(0);
  const [fault, setFault] = useState<null | "error" | "conflict">(null);

  const payload = useMemo(() => toPayload(state), [state]);
  const payloadKey = useMemo(() => JSON.stringify(payload), [payload]);
  const [savedKey, setSavedKey] = useState(() => JSON.stringify(toPayload(initial.state)));
  const dirty = payloadKey !== savedKey;

  // Refs hold what the async save needs to see at the moment it runs.
  const latest = useRef({ key: payloadKey, payload });
  const savedRef = useRef(savedKey);
  const version = useRef(initial.version);
  const chain = useRef<Promise<void>>(Promise.resolve());
  const stopped = useRef(false);
  useEffect(() => {
    latest.current = { key: payloadKey, payload };
  }, [payloadKey, payload]);

  /** Saves the newest draft after any save already in flight. Never two requests at once. */
  const run = useCallback((): Promise<void> => {
    chain.current = chain.current.then(async () => {
      if (stopped.current) return;
      const { key, payload: body } = latest.current;
      if (key === savedRef.current) return;
      try {
        const result = await saveDraftAction(
          initial.id,
          JSON.stringify({ ...body, version: version.current }),
        );
        if (result.ok) {
          version.current = result.version;
          savedRef.current = key;
          setSavedKey(key);
          setFault(null);
        } else if (result.conflict) {
          stopped.current = true;
          setFault("conflict");
        } else {
          setFault("error");
        }
      } catch {
        setFault("error");
      }
    });
    return chain.current;
  }, [initial.id]);

  // Save about 800 ms after the last change (and again if more changes arrived during a save).
  useEffect(() => {
    if (!dirty || fault === "conflict") return;
    const timer = setTimeout(() => void run(), 800);
    return () => clearTimeout(timer);
  }, [dirty, payloadKey, savedKey, fault, run]);

  // After a failed save, try again every 5 seconds.
  useEffect(() => {
    if (fault !== "error") return;
    const timer = setTimeout(() => void run(), 5000);
    return () => clearTimeout(timer);
  }, [fault, run]);

  // Warn before leaving the page with unsaved changes.
  useEffect(() => {
    if (!dirty && !fault) return;
    const warn = (e: BeforeUnloadEvent) => e.preventDefault();
    window.addEventListener("beforeunload", warn);
    return () => window.removeEventListener("beforeunload", warn);
  }, [dirty, fault]);

  // --- finishing ---------------------------------------------------------------------------------
  const [issueState, issueAction, issuing] = useActionState(issueQuoteAction, undefined);
  const issueForm = useRef<HTMLFormElement>(null);
  async function finish() {
    await run();
    if (stopped.current) return;
    issueForm.current?.requestSubmit();
  }

  // --- derived values for the screen -------------------------------------------------------------
  const lineInputs = useMemo(
    () =>
      state.lines.map((l) => ({
        id: l.key,
        lineKind: l.lineKind,
        billing: l.billing,
        frequency: l.frequency,
        description: l.description.trim(),
        amountCents: parseAmount(l.amountText),
        chosen: false,
      })),
    [state.lines],
  );
  const problems = useMemo(
    () =>
      validateForIssue(
        { validUntil: state.validUntil, scope: state.scope, lines: lineInputs },
        initial.today,
      ),
    [state.validUntil, state.scope, lineInputs, initial.today],
  );
  const doc = useMemo(() => {
    const date = new Date(`${state.validUntil}T00:00:00Z`);
    return buildQuoteDocument({
      status: "DRAFT",
      reference: null,
      issuedDate: null,
      validUntil: Number.isNaN(date.getTime()) ? "" : formatDate(date),
      preparedFor: initial.preparedFor,
      scope: state.scope.map((s) => ({
        name: s.name,
        description: s.description,
        kind: s.kind,
        included: s.included,
      })),
      lines: lineInputs,
      wording: snapshotWording(initial.wording, lineInputs, initial.org),
    });
  }, [state.validUntil, state.scope, lineInputs, initial.preparedFor, initial.wording, initial.org]);

  const suggestMonthly =
    state.scope.some((s) => s.included && s.kind === "CORE") &&
    !state.lines.some((l) => l.lineKind === "PRICED" && l.billing === "MONTHLY");

  function toggleService(serviceId: string) {
    setState((prev) => {
      const target = prev.scope.find((s) => s.serviceId === serviceId);
      if (!target) return prev;
      const nowIncluded = !target.included;
      const scope = prev.scope.map((s) =>
        s.serviceId === serviceId ? { ...s, included: nowIncluded } : s,
      );
      // Switching on an optional extra suggests an optional price line for it (once).
      const alreadyThere = prev.lines.some(
        (l) => l.lineKind === "OPTIONAL" && l.description === target.name,
      );
      const lines =
        nowIncluded && target.kind === "OPTIONAL_EXTRA" && !alreadyThere
          ? [
              ...prev.lines,
              blankLine({
                lineKind: "OPTIONAL",
                frequency: "AS_REQUIRED",
                description: target.name,
              }),
            ]
          : prev.lines;
      return { ...prev, scope, lines };
    });
  }

  const status =
    fault === "conflict"
      ? "Changed on another device. Reload the page."
      : fault === "error"
        ? "Could not save, retrying…"
        : dirty
          ? "Saving…"
          : "Saved";

  return (
    <div className="mx-auto max-w-3xl">
      <Link href="/quotes" className="inline-flex min-h-10 items-center text-sm text-forest hover:underline">
        ← Quotes
      </Link>
      <div className="mt-2 flex flex-wrap items-baseline justify-between gap-3">
        <h1 className="font-display text-2xl font-semibold text-forest">Draft quote</h1>
        <p
          role="status"
          aria-live="polite"
          className={`text-sm font-semibold ${fault ? "text-red-700" : "text-charcoal/60"}`}
        >
          {status}
        </p>
      </div>
      <p className="mt-1 text-charcoal">
        {initial.customerName}
        <span className="text-charcoal/60"> · {initial.siteLabel}</span>
      </p>
      {initial.revisionOfReference ? (
        <p className="mt-1 text-sm text-charcoal/60">
          Revision of {initial.revisionOfReference}. It keeps that number when issued.
        </p>
      ) : null}
      {initial.property.lawnSizeSqm || initial.property.accessNotes ? (
        <details className="mt-3 rounded-xl bg-white/70 p-3 text-sm ring-1 ring-charcoal/10">
          <summary className="min-h-10 cursor-pointer py-2 font-semibold text-forest">
            Property notes (staff only)
          </summary>
          <p className="text-charcoal/80">
            {initial.property.lawnSizeSqm ? `Lawn: ${initial.property.lawnSizeSqm} m². ` : ""}
            {initial.property.accessNotes ? `Access: ${initial.property.accessNotes}` : ""}
          </p>
        </details>
      ) : null}

      {fault === "conflict" ? (
        <p role="alert" className="mt-4 rounded-lg bg-red-50 px-3 py-2 text-sm text-red-800 ring-1 ring-red-200">
          This quote was changed somewhere else, so saving has stopped to protect that version.{" "}
          <a href="" className="font-semibold underline">
            Reload the page
          </a>{" "}
          to see the latest.
        </p>
      ) : null}

      <nav
        aria-label="Quote steps"
        className="sticky top-0 z-10 -mx-4 mt-4 flex gap-1 overflow-x-auto bg-cream/95 px-4 py-2 backdrop-blur"
      >
        {STEPS.map((name, index) => (
          <button
            key={name}
            type="button"
            onClick={() => setStep(index)}
            aria-current={index === step ? "step" : undefined}
            className={`min-h-10 whitespace-nowrap rounded-full px-4 text-sm font-semibold ring-1 ${
              index === step
                ? "bg-forest text-cream ring-forest"
                : "bg-white text-forest ring-charcoal/20"
            }`}
          >
            {index + 1}. {name}
          </button>
        ))}
      </nav>

      <div className="mt-4">
        {step === 0 ? <ScopeStep scope={state.scope} onToggle={toggleService} /> : null}
        {step === 1 ? (
          <LinesStep
            lines={state.lines}
            suggestMonthly={suggestMonthly}
            onChange={(lines) => setState((prev) => ({ ...prev, lines }))}
          />
        ) : null}
        {step === 2 ? (
          <DetailsStep
            validUntil={state.validUntil}
            internalNote={state.internalNote}
            today={initial.today}
            onValidUntil={(validUntil) => setState((prev) => ({ ...prev, validUntil }))}
            onNote={(internalNote) => setState((prev) => ({ ...prev, internalNote }))}
          />
        ) : null}
        {step === 3 ? (
          <div className="space-y-4">
            <TotalsSummary lines={state.lines} />
            {problems.length > 0 ? (
              <div role="status" className="rounded-xl bg-ochre/10 p-4 text-sm ring-1 ring-ochre/30">
                <p className="font-semibold text-charcoal">Before this can be issued:</p>
                <ul className="mt-1 list-disc space-y-0.5 pl-5 text-charcoal/80">
                  {problems.map((p) => (
                    <li key={p}>{p}</li>
                  ))}
                </ul>
              </div>
            ) : (
              <p className="rounded-xl bg-forest/5 p-4 text-sm font-semibold text-forest ring-1 ring-forest/20">
                Ready to issue.
              </p>
            )}
            <QuoteDocumentView doc={doc} />
            {issueState?.error ? (
              <p
                role="alert"
                className="whitespace-pre-line rounded-lg bg-red-50 px-3 py-2 text-sm text-red-800 ring-1 ring-red-200"
              >
                {issueState.error}
              </p>
            ) : null}
            <form ref={issueForm} action={issueAction}>
              <input type="hidden" name="id" value={initial.id} />
            </form>
            <button
              type="button"
              onClick={() => void finish()}
              disabled={problems.length > 0 || issuing || fault === "conflict"}
              className={buttonClass}
            >
              {issuing ? "Issuing…" : "Finish and issue"}
            </button>
          </div>
        ) : null}
      </div>

      <div className="mt-6 flex items-center justify-between gap-3">
        <button
          type="button"
          disabled={step === 0}
          onClick={() => setStep((s) => Math.max(0, s - 1))}
          className="min-h-10 rounded-full border border-forest/30 px-5 text-sm font-semibold text-forest disabled:opacity-40"
        >
          Back
        </button>
        <button
          type="button"
          disabled={step === STEPS.length - 1}
          onClick={() => setStep((s) => Math.min(STEPS.length - 1, s + 1))}
          className="min-h-10 rounded-full bg-forest px-5 text-sm font-semibold text-cream disabled:opacity-40"
        >
          Next
        </button>
      </div>

      <form
        action={deleteDraftAction}
        className="mt-10 border-t border-charcoal/10 pt-4"
        onSubmit={(e) => {
          if (!window.confirm("Delete this draft quote? This cannot be undone.")) e.preventDefault();
        }}
      >
        <input type="hidden" name="id" value={initial.id} />
        <button type="submit" className="min-h-10 text-sm font-semibold text-red-700 underline">
          Delete this draft
        </button>
      </form>
    </div>
  );
}

const sentMethod = z.enum(SENT_METHODS);
const BAD_REQUEST = "Something went wrong. Refresh the page and try again.";

export async function markSentAction(formData: FormData): Promise<void> {
  const staff = await requireStaff(MANAGEMENT);
  const actor = await toActor(staff);
  const id = idSchema.parse(formData.get("id"));
  const method = sentMethod.parse(formData.get("method"));
  try {
    await inTx((tx) => markSent(tx, actor, id, method));
  } catch (error) {
    failure(error);
  }
  redirect(`/quotes/${id}`);
}

export async function acceptQuoteAction(_prev: FormState, formData: FormData): Promise<FormState> {
  const staff = await requireStaff(MANAGEMENT);
  const actor = await toActor(staff);
  const values = formValues(formData);
  const id = idSchema.safeParse(values.id);
  if (!id.success) return { error: BAD_REQUEST, nonce: Date.now() };
  const parsed = acceptSchema.safeParse({
    method: values.method,
    acceptedBy: values.acceptedBy,
    startDate: values.startDate,
    chosenLineIds: formData.getAll("chosen").filter((v): v is string => typeof v === "string"),
    note: values.note ?? "",
  });
  if (!parsed.success) return { fieldErrors: errorsFrom(parsed.error), values, nonce: Date.now() };
  let flag: "PAUSED" | "ARCHIVED" | null;
  try {
    flag = (await inTx((tx) => acceptQuote(tx, actor, id.data, parsed.data))).customerFlag;
  } catch (error) {
    return failure(error, values);
  }
  redirect(flag ? `/quotes/${id.data}?notice=${flag.toLowerCase()}` : `/quotes/${id.data}`);
}

export async function declineQuoteAction(_prev: FormState, formData: FormData): Promise<FormState> {
  const staff = await requireStaff(MANAGEMENT);
  const actor = await toActor(staff);
  const values = formValues(formData);
  const id = idSchema.safeParse(values.id);
  if (!id.success) return { error: BAD_REQUEST, nonce: Date.now() };
  const parsed = declineSchema.safeParse({ reason: values.reason ?? "" });
  if (!parsed.success) return { fieldErrors: errorsFrom(parsed.error), values, nonce: Date.now() };
  try {
    await inTx((tx) => declineQuote(tx, actor, id.data, parsed.data));
  } catch (error) {
    return failure(error, values);
  }
  redirect(`/quotes/${id.data}`);
}

/** Copies the quote into a new draft and opens the builder on it. */
export async function reviseQuoteAction(formData: FormData): Promise<void> {
  const staff = await requireStaff(MANAGEMENT);
  const actor = await toActor(staff);
  const id = idSchema.parse(formData.get("id"));
  let draftId: string;
  try {
    draftId = (await inTx((tx) => reviseQuote(tx, actor, id))).id;
  } catch (error) {
    failure(error);
    redirect(`/quotes/${id}`);
  }
  redirect(`/quotes/${draftId}`);
}

export async function reverseAcceptanceAction(
  _prev: FormState,
  formData: FormData,

  } catch (error) {
    return failure(error, values);

}

import {
  ACCEPT_METHOD_LABELS,
  SENT_METHOD_LABELS,
  formatZAR,
  type getQuote,
} from "@ace/core";
import { formatDate, formatDateTime } from "@/lib/format";

type Quote = NonNullable<Awaited<ReturnType<typeof getQuote>>>;

function Row({ label, children }: { label: string; children: React.ReactNode }) {
  return (
    <div>
      <dt className="inline text-charcoal/60">{label}: </dt>
      <dd className="inline">{children}</dd>
    </div>
  );
}

export function QuoteFacts({ quote }: { quote: Quote }) {
  const chosen = quote.lines.filter((l) => l.lineKind === "OPTIONAL" && l.chosen);
  const rows: React.ReactNode[] = [];
  if (quote.sentAt) {
    rows.push(
      <Row key="sent" label="Sent">
        {formatDateTime(quote.sentAt)}
        {quote.sentMethod ? ` by ${SENT_METHOD_LABELS[quote.sentMethod]}` : ""}
      </Row>,
    );
  }
  if (quote.status === "ACCEPTED" && quote.acceptedAt) {
    rows.push(
      <Row key="accepted" label="Accepted">
        {formatDateTime(quote.acceptedAt)}
        {quote.acceptedMethod ? ` (${ACCEPT_METHOD_LABELS[quote.acceptedMethod]})` : ""}
        {quote.acceptedByName ? ` by ${quote.acceptedByName}` : ""}
      </Row>,
    );
    if (quote.acceptedStartDate) {
      rows.push(
        <Row key="start" label="Service starts">
          {formatDate(quote.acceptedStartDate)}
        </Row>,
      );
    }
    rows.push(
      <Row key="options" label="Optional add-ons chosen">
        {chosen.length === 0
          ? "none"
          : chosen.map((l) => `${l.description} (${formatZAR(l.amountCents ?? 0)})`).join(", ")}
      </Row>,
    );
    if (quote.acceptanceNote) {
      rows.push(
        <Row key="note" label="Note">
          {quote.acceptanceNote}
        </Row>,
      );
    }
    if (quote.agreementEndedAt) {
      rows.push(
        <Row key="ended" label="Agreement">
          replaced by a newer accepted quote on {formatDate(quote.agreementEndedAt)}
        </Row>,
      );
    }
  }
  if (quote.status === "DECLINED" && quote.declinedAt) {
    rows.push(
      <Row key="declined" label="Declined">
        {formatDateTime(quote.declinedAt)}
        {quote.declineReason ? `: ${quote.declineReason}` : ""}
      </Row>,
    );
  }
  if (quote.reversedAt) {
    rows.push(
      <Row key="reversed" label="Last reversal">
        {formatDateTime(quote.reversedAt)}
        {quote.reversalNote ? `: ${quote.reversalNote}` : ""}
      </Row>,
    );
  }
  if (rows.length === 0) return null;
  return <dl className="space-y-1 rounded-2xl bg-white/70 p-4 text-sm ring-1 ring-charcoal/10">{rows}</dl>;
}

const FREQUENCIES: Record<string, string> = {
  WEEKLY: "weekly",
  FORTNIGHTLY: "every two weeks",
  MONTHLY: "monthly",
  AS_REQUIRED: "as required",

function lineText(l: AgreementQuote["lines"][number]): string {
  if (l.lineKind === "INCLUDED") return `${l.description} (included)`;

}

import { renderToBuffer } from "@react-pdf/renderer";
import { createElement } from "react";
import { z } from "zod";
import { toActor } from "@/lib/actor";

export async function GET(_request: Request, { params }: { params: Promise<{ id: string }> }) {
  const staff = await requireStaff(["OWNER", "MANAGER"]); // every route starts with this
  const { id } = await params;
  if (!z.uuid().safeParse(id).success) return new Response("Not found", { status: 404 });
  const actor = await toActor(staff);
  const quote = await getQuote(getDb(), actor, id);
  // A draft has no number and is not a document yet.
  if (!quote || quote.status === "DRAFT") return new Response("Not found", { status: 404 });

  const { doc } = await loadDocument(quote, actor);
  const buffer = await renderToBuffer(createElement(QuotePdf, { doc }));
  const filename = `${doc.reference.replaceAll(" ", "-")}.pdf`;
  return new Response(new Uint8Array(buffer), {
    headers: {
      "Content-Type": "application/pdf",
      "Content-Disposition": `inline; filename="${filename}"`,
      "Cache-Control": "private, no-store",
    },
  });
}

"use server";

import { inTx, updateQuoteWording, wordingSchema } from "@ace/core";
import { redirect } from "next/navigation";
import { toActor } from "@/lib/actor";
import { requireStaff } from "@/lib/auth";
import { failure, type FormState } from "@/lib/form";

const AREAS: Record<string, string> = {
  tagline: "Tagline",
  standardExclusions: "Standard exclusions",
  monthlyTerms: "Monthly terms",
  onceOffTerms: "Once-off terms",
  commonTerms: "General terms",
  everyVisitPoints: "Every visit points",
  defaultValidityDays: "Default validity",
  registrationNumber: "Registration number",
  phone: "Phone",
  email: "Email",
  website: "Website",
};

export async function saveWordingAction(_prev: FormState, formData: FormData): Promise<FormState> {
  const staff = await requireStaff(["OWNER"]);
  const actor = await toActor(staff);
  let raw: unknown;
  try {
    raw = JSON.parse(String(formData.get("payload") ?? ""));
  } catch {
    return { error: "Something went wrong. Refresh the page and try again.", nonce: Date.now() };
  }
  const parsed = wordingSchema.safeParse(raw);
  if (!parsed.success) {
    const issue = parsed.error.issues[0];
    const area = AREAS[String(issue?.path[0] ?? "")] ?? "Wording";
    const row = typeof issue?.path[1] === "number" ? ` (item ${issue.path[1] + 1})` : "";
    return { error: `${area}${row}: ${issue?.message ?? "not valid."}`, nonce: Date.now() };
  }
  try {
    await inTx((tx) => updateQuoteWording(tx, actor, parsed.data));
  } catch (error) {
    return failure(error);
  }
  redirect("/settings/quote-wording?saved=1");
}
