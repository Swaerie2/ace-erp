# Module 3b: The Private Client Link Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A client opens a private link (`<portal>/q/<code>`), reads their quote, chooses their optional add-ons and presses Accept or Decline, with no login. The acceptance does exactly what a staff-recorded one does. The portal app reaches the database only through its own low-privilege role (`ace_portal`) and a handful of reviewed functions.

**Architecture:** Core (`packages/core/src/quotes`) gains a shared acceptance routine (used by the staff function and the client-link function), link management, and five public functions that take no `Actor` and use explicit column lists so they work under column-level database grants. A migration adds the link columns, a rate-limit table and the `ace_portal` role with minimal grants. The quote document and PDF components move into a new shared package `@ace/ui`. The portal app gets the `/q/[token]` pages, actions and PDF route. The staff app gets a client-link panel.

**Tech Stack:** Next.js 16.4 (App Router, server actions), React 19, TypeScript strict, Prisma 7 with `@prisma/adapter-pg`, Supabase Postgres, zod 4, vitest 5, Tailwind 4, `@react-pdf/renderer`.

**Spec:** `docs/superpowers/specs/2026-11-21-quotes-3b-design.md` (read all of it; it is short). The approved Module 3 spec (`2026-11-19-quotes-design.md`) and the phase 3a code (merged) are the base.

## Global Constraints

- Not VAT registered; money is whole cents, shown with `formatZAR`. No em dashes in any text shown on screen or printed.
- **Every database call in the public path (the five public functions and the shared acceptance routine) names its columns with `select`** (`findUnique`, `findMany`, `findFirst`, `update`, `create`, `aggregate` all take an explicit `select` or return only what is granted), because the `ace_portal` role has column-level grants only. `updateMany`, `deleteMany` and `count` are fine. `recordAudit` selects only `id`.
- Lock order everywhere: customer, then property, then quote. Every status-dependent write is a conditional `updateMany` or re-reads and re-checks after taking the lock.
- Audit lines hold field names, ids and fixed words only: never the typed name, notes, reasons, IP address, browser string or the link code. The client-link audit actor type is `CUSTOMER` with the customer id as actor id.
- The link code is a secret that opens personal data: 32 random bytes as base64url (43 characters), stored in `quotes.linkToken`, never logged, never put in an audit line, never shown to anyone but staff, and set to null when a customer is anonymised.
- Every page, action and route in the **staff app** keeps calling `requireStaff` first (owner or manager for the client-link controls). The **portal app has no staff session**: its only authority is possession of a valid code. Unknown, revoked, malformed and draft codes all produce the same 404 page.
- Responses from `/q/*` in the portal: `Cache-Control: private, no-store`, `X-Robots-Tag: noindex, nofollow`, `Referrer-Policy: no-referrer` (plus the existing security headers). Page titles and descriptions never contain customer details.
- Client components never import values from `@ace/core` (types are fine); the staff app uses `@ace/core/client` in client components. The portal's client components import nothing from core except types.
- Pages work at 375px with no sideways scroll; interactive controls are at least 40px high.
- Database tests run only against the DEV database in always-rolled-back transactions (`npm run test:db`; about 8 minutes; testTimeout 90s; if the machine sleeps mid-run connections drop and the run is repeated). CI skips them.
- Formatting: never run the root `npm run format` (Windows line-ending noise). Format only files you touched with `npx prettier --write <paths>`. `npm run check` ends red on a line-ending noise in an untouched file; that one is known.
- Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Commit locally after each task. Do not push. **Never apply a migration yourself**: Task 3 (apply) belongs to the controller and needs the owner's approval.
- Windows: PowerShell needs `npm.cmd`; Git Bash is fine with `npm run`. Do not run `npm run build` while a dev server is running.
- Lessons from phase 3a reviews, apply them: unlocked reads then lock then re-read; conditional updates; refuse anonymised customers before writing personal text; tests assert real behaviour and the audit holds no typed text; `noUncheckedIndexedAccess` is on; React hooks lint rules apply (no ref writes during render, no synchronous setState in an effect body).

```ts
/** 32 random bytes as base64url: 43 URL-safe characters, 256 bits. */
export function generateLinkToken(): string {
  return randomBytes(32).toString("base64url");
}

export function isLinkTokenShape(value: string): boolean {
  return /^[A-Za-z0-9_-]{43}$/.test(value);
}
```

`bots.ts`:

```ts
import { createHash } from "node:crypto";

const PREVIEW_BOTS =
  /whatsapp|facebookexternalhit|facebot|twitterbot|telegrambot|slackbot|slack-imgproxy|discordbot|linkedinbot|googlebot|bingbot|applebot|skypeuripreview|pinterestbot|embedly|vkshare|crawler|spider|preview|\bbot\b|bot\//i;

/** Link previews and crawlers get a bare page and never count as a view. A missing user agent counts too. */
export function isPreviewBot(userAgent: string | null | undefined): boolean {
  if (!userAgent || !userAgent.trim()) return true;
  return PREVIEW_BOTS.test(userAgent);
}

/** The visitor's address as a hash, so the rate limiter never stores the address itself. */
export function hashIp(ip: string): string {
  return createHash("sha256").update(`ace-link-v1:${ip}`).digest("hex");
}
```

`public-state.ts`:

```ts
import { displayStatus, type QuoteStatusValue } from "./reference";

export type PublicViewState = "OPEN" | "EXPIRED" | "ACCEPTED" | "DECLINED" | "REPLACED" | "WITHDRAWN";

/** What a visitor to the private link should be shown. A draft is never visible. */
export function publicViewState(
  q: { status: QuoteStatusValue; validUntil: Date },
  today?: string,
): PublicViewState | null {
  if (q.status === "DRAFT") return null;
  if (q.status === "ISSUED") {
    return displayStatus(q, today) === "EXPIRED" ? "EXPIRED" : "OPEN";
  }
  return q.status;
}
```

`rate-limit-window.ts`:

```ts
export const RATE_WINDOW_MINUTES = 10;
/** Page views and PDF downloads per visitor per window. */
export const VIEW_LIMIT = 120;
/** Accept or decline attempts per visitor per window. */
export const ACT_LIMIT = 10;

export type RateKind = "view" | "act";

export function windowStartFor(now: Date = new Date()): Date {
  const ms = RATE_WINDOW_MINUTES * 60_000;
  return new Date(Math.floor(now.getTime() / ms) * ms);
}

export function rateBucket(kind: RateKind, ipHash: string): string {
  return `${kind}:${ipHash}`;
}
```

```ts
 * The activation rule without any role check, for use only after the caller has done its own checks
 * (a staff role check, or a valid quote acceptance). Reads only the columns it needs.

export async function activateCustomerInternal(
  store: Pick<Db, "customer" | "auditLog">,
  party: AuditParty,
  id: string,
  opts: { via?: "quote" } = {},
): Promise<void> {
  /** True when there is something to do; throws for an archived customer. */
  const needsActivating = (status: CustomerStatus) => {
    if (status === "ARCHIVED") {
      throw new DomainError("Restore this customer before marking it as active.");
    }
    return status === "LEAD" || status === "PAUSED";
  };
  // Look first WITHOUT locking, so an already active customer is left completely untouched.
  if (!needsActivating((await findEditableCustomerNarrow(store, id)).status)) return;
  // Then lock and decide again from a fresh read: a concurrent change may have landed in between.
  await lockCustomer(store, id);
  const existing = await findEditableCustomerNarrow(store, id);
  if (!needsActivating(existing.status)) return;
  await store.customer.update({ where: { id }, data: { status: "ACTIVE" }, select: { id: true } });
  // Only the previous status is recorded (it is not personal data).
  await logCustomerEventAs(store, party, "customer.activated", id, {
    from: existing.status,
    ...(opts.via ? { via: opts.via } : {}),
  });
}
```

```ts
import { DomainError } from "../customers/access";
import { activateCustomerInternal } from "../customers/customers";
import { findEditableCustomerNarrow, lockCustomer } from "../customers/store";
import type { AuditParty } from "../audit";
import type { Db } from "../db";
import type { Prisma } from "../generated/prisma/client";
import { displayStatus, fromDateString, todaySA } from "./reference";
import { logQuoteEventAs, lockQuote, type QuoteStore } from "./store";

/** What the acceptance routines need. A subset of every store that may call them (staff or portal). */
export type AcceptStore = Pick<Db, "quote" | "quoteLine" | "customer" | "property" | "auditLog">;

/** The quote is not in the state this action needs. `status` is the status found. */
export class QuoteNotIssuedError extends DomainError {
  readonly status: string;
  constructor(status: string, message: string) {
    super(message);
    this.name = "QuoteNotIssuedError";
    this.status = status;
  }
}

export class QuoteExpiredError extends DomainError {
  constructor() {
    super("This quote has expired. Revise it to give it new dates.");
    this.name = "QuoteExpiredError";
  }
}

export type AcceptContext = {
  audit: AuditParty;
  method: "WHATSAPP" | "EMAIL" | "PHONE" | "IN_PERSON" | "SIGNED_COPY" | "CLIENT_LINK";
  /** The staff member who recorded it; null when the client accepted on the link. */
  staffId: string | null;
  ip: string | null;
  userAgent: string | null;
};

/** A monthly agreement means a priced monthly line, or an optional monthly line the client chose. */
const MONTHLY_AGREEMENT: Prisma.QuoteLineWhereInput = {
  billing: "MONTHLY",
  OR: [{ lineKind: "PRICED" }, { lineKind: "OPTIONAL", chosen: true }],
};

const ACCEPT_SELECT = {
  id: true,
  customerId: true,
  propertyId: true,
  status: true,
  validUntil: true,
  lines: { select: { id: true, lineKind: true, billing: true } },
} as const satisfies Prisma.QuoteSelect;

async function readForAccept(store: AcceptStore, id: string) {
  const quote = await store.quote.findUnique({ where: { id }, select: ACCEPT_SELECT });
  if (!quote) throw new DomainError("That quote could not be found.");
  return quote;
}

/**
 * The acceptance rules, shared by staff (recording an acceptance) and the client link. Every read names
 * its columns. Lock order: customer, then property, then quote. The caller must run it inside a
 * transaction and do any role or token check first.
 */
export async function acceptCore(
  store: AcceptStore,
  ctx: AcceptContext,
  quoteId: string,
  input: {
    acceptedBy: string;
    startDate: string;
    chosenLineIds: string[];
    note?: string | undefined;
  },
): Promise<{ customerFlag: "PAUSED" | "ARCHIVED" | null }> {
  const check = (q: Awaited<ReturnType<typeof readForAccept>>) => {
    if (q.status !== "ISSUED") {
      throw new QuoteNotIssuedError(q.status, "Only an issued quote can be accepted.");
    }
    if (displayStatus(q) === "EXPIRED") throw new QuoteExpiredError();
  };
  // Look first, without any lock, so a refused request takes no lock at all.
  const first = await readForAccept(store, quoteId);
  check(first);
  if (input.startDate < todaySA()) throw new DomainError("The start date must be today or later.");
  // The customer lock (refused for an anonymised customer) stops personal text being written back onto
  // one; the property lock makes accepts and reversals for one property take turns.
  await findEditableCustomerNarrow(store, first.customerId);
  await lockCustomer(store, first.customerId);
  await store.property.updateMany({
    where: { id: first.propertyId },
    data: { updatedAt: new Date() },
  });
  await lockQuote(store as QuoteStore, quoteId);
  const quote = await readForAccept(store, quoteId);
  check(quote);
  const chosenIds = [...new Set(input.chosenLineIds)];
  const optionalIds = new Set(quote.lines.filter((l) => l.lineKind === "OPTIONAL").map((l) => l.id));
  if (chosenIds.some((lineId) => !optionalIds.has(lineId))) {
    throw new DomainError("Only optional add-ons can be chosen.");
  }

  await store.quoteLine.updateMany({
    where: { quoteId, id: { in: chosenIds } },
    data: { chosen: true },
  });
  await store.quote.update({
    where: { id: quoteId },
    data: {
      status: "ACCEPTED",
      acceptedAt: new Date(),
      acceptedMethod: ctx.method,
      acceptedByName: input.acceptedBy,
      acceptedStartDate: fromDateString(input.startDate),
      acceptanceNote: input.note ?? null,
      acceptedByStaffId: ctx.staffId,
      acceptedIp: ctx.ip,
      acceptedUserAgent: ctx.userAgent,
      // A freshly accepted quote starts as a live agreement.
      agreementEndedAt: null,
      agreementReplacedById: null,
    },
    select: { id: true },
  });

  // Agreement rule: a newly accepted monthly quote replaces the property's earlier monthly agreement.
  const isMonthly = quote.lines.some(
    (l) =>
      l.billing === "MONTHLY" &&
      (l.lineKind === "PRICED" || (l.lineKind === "OPTIONAL" && chosenIds.includes(l.id))),
  );
  if (isMonthly) {
    const earlier = await store.quote.findMany({
      where: {
        propertyId: quote.propertyId,
        status: "ACCEPTED",
        agreementEndedAt: null,
        id: { not: quoteId },
        lines: { some: MONTHLY_AGREEMENT },
      },
      select: { id: true },
    });
    for (const old of earlier) {
      // Conditional, so a quote that changed state in the meantime is never marked as replaced.
      const { count } = await store.quote.updateMany({
        where: { id: old.id, status: "ACCEPTED", agreementEndedAt: null },
        data: { agreementEndedAt: new Date(), agreementReplacedById: quoteId },
      });
      if (count === 1) {
        await logQuoteEventAs(store, ctx.audit, "quote.agreement_ended", old.id, { replacedBy: quoteId });
      }
    }
  }

  // A lead becomes active. A paused or archived customer is left alone and flagged.
  const customer = await store.customer.findUniqueOrThrow({
    where: { id: quote.customerId },
    select: { status: true },
  });
  let customerFlag: "PAUSED" | "ARCHIVED" | null = null;
  if (customer.status === "LEAD") {
    await activateCustomerInternal(store, ctx.audit, quote.customerId, { via: "quote" });
  } else if (customer.status === "PAUSED" || customer.status === "ARCHIVED") {
    customerFlag = customer.status;
  }

  await logQuoteEventAs(store, ctx.audit, "quote.accepted", quoteId, {
    method: ctx.method,
    optionsChosen: chosenIds.length,
    customerFlag,
  });
  return { customerFlag };
}

/** Declining: ISSUED only. Lock order customer, then quote. */
export async function declineCore(
  store: AcceptStore,
  ctx: { audit: AuditParty; declinedByClient: boolean },
  quoteId: string,
  input: { reason?: string | undefined },
): Promise<void> {
  const read = async () => {
    const quote = await store.quote.findUnique({
      where: { id: quoteId },
      select: { id: true, customerId: true, status: true },
```

```ts
import { assertRole, DomainError, MANAGEMENT, type Actor } from "../customers/access";
import { findEditableCustomer } from "../customers/store";
import { findQuote, lockQuote, logQuoteEvent, type QuoteStore } from "./store";
import { generateLinkToken } from "./token";

const LINKABLE = ["ISSUED", "ACCEPTED", "DECLINED"];
const NOT_LINKABLE = "A link can only be made for an issued, accepted or declined quote.";

/**
 * Creates the private client link for a quote (or returns the existing one). With `replace` a fresh code is
 * made and the old one stops working. The code is never written to the audit log.
 */
export async function createQuoteLink(
  store: QuoteStore,
  actor: Actor,
  id: string,
  opts: { replace?: boolean } = {},
): Promise<{ token: string }> {
  assertRole(actor, MANAGEMENT);
  const first = await findQuote(store, id);
  if (!LINKABLE.includes(first.status)) throw new DomainError(NOT_LINKABLE);
  await findEditableCustomer(store, first.customerId);
  await lockQuote(store, id);
  const quote = await findQuote(store, id);
  if (!LINKABLE.includes(quote.status)) throw new DomainError(NOT_LINKABLE);
  if (quote.linkToken && !opts.replace) return { token: quote.linkToken };
  const token = generateLinkToken();
  await store.quote.update({
    where: { id },
    data: { linkToken: token, linkCreatedAt: new Date(), firstViewedAt: null, lastViewedAt: null },
    select: { id: true },
  });
  await logQuoteEvent(store, actor, "quote.link_created", id, { replaced: Boolean(quote.linkToken) });
  return { token };
}

/** Stops the private link working. Nothing happens if there is no link. */
export async function revokeQuoteLink(store: QuoteStore, actor: Actor, id: string): Promise<void> {
  assertRole(actor, MANAGEMENT);
  if (!(await findQuote(store, id)).linkToken) return;
  await lockQuote(store, id);
  if (!(await findQuote(store, id)).linkToken) return;
  await store.quote.update({
    where: { id },
    data: { linkToken: null },
    select: { id: true },
  });
  await logQuoteEvent(store, actor, "quote.link_revoked", id);
}
```

```ts
/** Finds a quote by its private code. Wrong, malformed, revoked and draft codes all give `{ found: false }`. */
export async function getPublicQuote(
  store: PublicStore,
  token: string,
  now: Date = new Date(),
): Promise<PublicQuoteResult> {
  if (!isLinkTokenShape(token)) return { found: false };
  const q = await store.quote.findUnique({ where: { linkToken: token }, select: PUBLIC_QUOTE_SELECT });
  if (!q) return { found: false };
  const state = publicViewState(q);
  if (!state) return { found: false };

  const wording = wordingSnapshotSchema.parse(q.wordingSnapshot);
  const reference = formatQuoteReference(q) ?? "";
  const lines = q.lines.map((l) => ({
    id: l.id,
    lineKind: l.lineKind,
    billing: l.billing,
    frequency: l.frequency,
    description: l.description,
    amountCents: l.amountCents,
    chosen: l.chosen,
  }));
  const doc = buildQuoteDocument({
    status: displayStatus(q),
    reference,
    issuedDate: q.issuedAt ? formatDateSA(q.issuedAt) : null,
    validUntil: formatDateSA(q.validUntil),
    // Name and property address only: the email and phone are never read.
    preparedFor: {
      name: q.recipientName ?? "Anonymised customer",
      email: null,
      phone: null,
      siteLabel: q.siteLabel ?? "",
      siteAddress: q.siteAddress ?? "",
    },
    scope: q.scopeItems,
    lines,
    wording,
  });

  let newerToken: string | null = null;
  if (state === "REPLACED" && q.numberYear !== null && q.numberSeq !== null) {
    const newer = await store.quote.findFirst({
      where: {
        numberYear: q.numberYear,
        numberSeq: q.numberSeq,
        revision: { gt: q.revision },
        status: { in: ["ISSUED", "ACCEPTED"] },
        linkToken: { not: null },
      },
      orderBy: { revision: "desc" },
      select: { linkToken: true },
    });
    newerToken = newer?.linkToken ?? null;
  }

  const optionalLines = lines
    .filter((l) => l.lineKind === "OPTIONAL")
    .map((l) => ({
      id: l.id,
      label: `${l.description} (${formatZAR(l.amountCents ?? 0)}${l.billing === "MONTHLY" ? " per month" : ""})`,
    }));

  const acceptance =
    state === "ACCEPTED" && q.acceptedAt
      ? {
          name: q.acceptedByName,
          at: formatDateTimeSA(q.acceptedAt),
          startDate: q.acceptedStartDate ? formatDateSA(q.acceptedStartDate) : null,
          chosen: lines
            .filter((l) => l.lineKind === "OPTIONAL" && l.chosen)
            .map((l) => `${l.description} (${formatZAR(l.amountCents ?? 0)})`),
        }
      : null;

  void now;
  return {
    found: true,
    state,
    reference,
    doc,
    optionalLines,
    acceptance,
    declinedAt: q.declinedAt ? formatDateTimeSA(q.declinedAt) : null,
    newerToken,
    business: {
      tradingName: wording.business.tradingName,
      phone: wording.business.phone,
      email: wording.business.email,
    },
  };
}

/** Records that the link was opened: first view once, last view every time. Only for a live link. */
export async function recordLinkView(
  store: PublicStore,
  token: string,
  now: Date = new Date(),
): Promise<void> {
  if (!isLinkTokenShape(token)) return;

    linkToken: token,

}

  | { outcome: "NOT_FOUND" };

/** The client accepts on the private link. Call inside a transaction. Plain DomainErrors propagate. */
export async function acceptViaLink(
  store: PublicStore,
  token: string,
  input: LinkAcceptInput,
  ctx: LinkContext,
): Promise<LinkAcceptResult> {
  if (!isLinkTokenShape(token)) return { outcome: "NOT_FOUND" };
  const found = await store.quote.findUnique({
    where: { linkToken: token },
    select: { id: true, customerId: true, status: true },
  });
  if (!found || found.status === "DRAFT") return { outcome: "NOT_FOUND" };
  if (found.status === "ACCEPTED") return { outcome: "ALREADY_ACCEPTED" };
  if (found.status !== "ISSUED") return { outcome: "NOT_AVAILABLE" };
  try {
    const { customerFlag } = await acceptCore(
      store,
      {
        audit: clientParty(found.customerId),
        method: "CLIENT_LINK",
        staffId: null,
        ip: ctx.ip,
        userAgent: ctx.userAgent,
      },
      found.id,
      input,
    );
    return { outcome: "ACCEPTED", customerFlag };
  } catch (error) {
    if (error instanceof QuoteExpiredError) return { outcome: "EXPIRED" };
    if (error instanceof QuoteNotIssuedError) {
      return error.status === "ACCEPTED" ? { outcome: "ALREADY_ACCEPTED" } : { outcome: "NOT_AVAILABLE" };
    }
    throw error;
  }
}

/** The client declines on the private link. Call inside a transaction. */
export async function declineViaLink(
  store: PublicStore,
  token: string,
  input: LinkDeclineInput,
  ctx: LinkContext,
): Promise<
  | { outcome: "DECLINED" }
  | { outcome: "ALREADY_DECLINED" }
  | { outcome: "NOT_AVAILABLE" }
  | { outcome: "NOT_FOUND" }
> {
  void ctx;
  if (!isLinkTokenShape(token)) return { outcome: "NOT_FOUND" };
  const found = await store.quote.findUnique({
    where: { linkToken: token },
    select: { id: true, customerId: true, status: true },
  });
  if (!found || found.status === "DRAFT") return { outcome: "NOT_FOUND" };
  if (found.status === "DECLINED") return { outcome: "ALREADY_DECLINED" };
  if (found.status !== "ISSUED") return { outcome: "NOT_AVAILABLE" };
  try {
    await declineCore(store, { audit: clientParty(found.customerId), declinedByClient: true }, found.id, input);
    return { outcome: "DECLINED" };
  } catch (error) {
    if (error instanceof QuoteNotIssuedError) {
      return error.status === "DECLINED" ? { outcome: "ALREADY_DECLINED" } : { outcome: "NOT_AVAILABLE" };
    }
    throw error;
  }
}

/**
 * Counts one request for this visitor (already hashed) in the current 10-minute window, with one atomic
 * statement, and says whether it is still within the limit. About one call in a hundred also deletes
 * windows older than a day (`opts.cleanup` forces or prevents this, for tests).
 */
export async function checkRateLimit(
  store: PublicStore,
  kind: RateKind,
  ipHash: string,
  opts: { now?: Date; cleanup?: boolean } = {},
): Promise<{ allowed: boolean }> {
  const now = opts.now ?? new Date();
  const bucket = rateBucket(kind, ipHash);
  const windowStart = windowStartFor(now);
  const rows = await store.$queryRaw<{ count: number }[]>`
    insert into public_link_hits ("bucket", "windowStart", "count") values (${bucket}, ${windowStart}, 1)
    on conflict ("bucket", "windowStart") do update set "count" = public_link_hits."count" + 1
    returning "count"`;
  const count = Number(rows[0]?.count ?? 1);
  if (opts.cleanup ?? Math.random() < 0.01) {
    await store.publicLinkHit.deleteMany({
      where: { windowStart: { lt: new Date(now.getTime() - 24 * 60 * 60 * 1000) } },
    });
  }
  return { allowed: count <= (kind === "view" ? VIEW_LIMIT : ACT_LIMIT) };
}
```

```ts
// eslint-disable-next-line no-control-regex -- control characters are exactly what is being removed
const CONTROL = /[\u0000-\u001f\u007f]/g;
const IP_SHAPE = /^[0-9a-fA-F:.]{2,45}$/;

/**
 * The visitor's address from the host's forwarding headers: the first address in `x-forwarded-for`, else
 * `x-real-ip`. Anything that does not look like an address is ignored. Used only for the rate limiter
 * (hashed) and as proof on an acceptance.
 */
export function clientIpFromHeaders(get: (name: string) => string | null): string | null {
  const forwarded = get("x-forwarded-for")?.split(",")[0]?.trim() ?? "";
  if (IP_SHAPE.test(forwarded)) return forwarded;
  const real = get("x-real-ip")?.trim() ?? "";
  return IP_SHAPE.test(real) ? real : null;
}

/** A browser string made safe to store: no control characters, at most 300 characters, null when empty. */
export function cleanUserAgent(value: string | null): string | null {
  const cleaned = (value ?? "").replace(CONTROL, "").trim().slice(0, 300);
  return cleaned === "" ? null : cleaned;
}
```

```ts
"use server";

import {
  DomainError,
  acceptViaLink,
  checkRateLimit,
  declineViaLink,
  getPortalDb,
  inPortalTx,
  linkAcceptSchema,
  linkDeclineSchema,
} from "@ace/core";
import { redirect } from "next/navigation";
import { z } from "zod";
import { getVisitor, type Visitor } from "@/lib/visitor";
import type { FormState } from "./form-state";

const TRY_AGAIN = "Too many attempts. Please wait ten minutes and try again.";
const BAD_REQUEST = "Something went wrong. Refresh the page and try again.";

function formValues(formData: FormData): Record<string, string> {
  const out: Record<string, string> = {};
  for (const [key, value] of formData.entries()) {
    if (typeof value === "string") out[key] = value;
  }
  return out;
}

function errorsFrom(error: z.ZodError): Record<string, string> {
  const out: Record<string, string> = {};
  for (const [field, messages] of Object.entries(z.flattenError(error).fieldErrors)) {
    const message = (messages as string[] | undefined)?.[0];
    if (message) out[field] = message;
  }
  return out;
}

/** Counts the attempt against the visitor's allowance. Refuses crawlers and clients with no browser string. */
async function guard(): Promise<{ visitor: Visitor } | { refused: FormState }> {
  const visitor = await getVisitor();
  if (visitor.isBot) return { refused: { error: BAD_REQUEST, nonce: Date.now() } };
  if (!(await checkRateLimit(getPortalDb(), "act", visitor.ipHash)).allowed) {
    return { refused: { error: TRY_AGAIN, nonce: Date.now() } };
  }
  return { visitor };
}

/**
 * Every outcome except a typing mistake goes back to the page, which then shows the true state (accepted,
 * expired, withdrawn, not found...). This also makes a double tap harmless.
 */
const backToPage = (token: string): never => redirect(`/q/${encodeURIComponent(token)}`);

export async function acceptAction(
  token: string,
  _prev: FormState,
  formData: FormData,
): Promise<FormState> {
  const guarded = await guard();
  if ("refused" in guarded) return guarded.refused;
  const chosen = formData.getAll("chosen").filter((v): v is string => typeof v === "string");
  const values = { ...formValues(formData), chosen: chosen.join(",") };
  if (formData.get("agree") !== "on") {
    return {
      fieldErrors: { agree: "Tick the box to accept this quotation." },
      values,
      nonce: Date.now(),
    };
  }
  const parsed = linkAcceptSchema.safeParse({
    acceptedBy: values.acceptedBy ?? "",
    startDate: values.startDate ?? "",
    chosenLineIds: chosen,
  });
  if (!parsed.success) return { fieldErrors: errorsFrom(parsed.error), values, nonce: Date.now() };
  try {
    await inPortalTx((tx) =>
      acceptViaLink(tx, token, parsed.data, {
        ip: guarded.visitor.ip,
        userAgent: guarded.visitor.userAgent,
      }),
    );
  } catch (error) {
    // Plain refusals (a start date in the past, a line that is not an add-on) are shown with the form.
    if (error instanceof DomainError) return { error: error.message, values, nonce: Date.now() };
    throw error;
  }
  return backToPage(token);
}

export async function declineAction(
  token: string,
  _prev: FormState,
  formData: FormData,
): Promise<FormState> {
  const guarded = await guard();
  if ("refused" in guarded) return guarded.refused;
  const values = formValues(formData);
  const parsed = linkDeclineSchema.safeParse({ reason: values.reason ?? "" });
  if (!parsed.success) return { fieldErrors: errorsFrom(parsed.error), values, nonce: Date.now() };
  try {
    await inPortalTx((tx) =>
      declineViaLink(tx, token, parsed.data, {
        ip: guarded.visitor.ip,
        userAgent: guarded.visitor.userAgent,
      }),
    );
  } catch (error) {
    if (error instanceof DomainError) return { error: error.message, values, nonce: Date.now() };
    throw error;
  }
  return backToPage(token);
}
```

```tsx
  "inline-flex min-h-11 items-center text-sm font-semibold text-forest underline";

export default async function QuoteLinkPage({ params }: { params: Promise<{ token: string }> }) {
  const { token } = await params;
  const visitor = await getVisitor();
  // Link previews, crawlers and clients with no browser string: no quote data is read and no view is recorded.
  if (visitor.isBot) return <BarePage />;

    case "WITHDRAWN":

          <Notice title="This quotation has been withdrawn">{contact}</Notice>
        </PageShell>

        </PageShell>
      );
    case "DECLINED":
      return (
        <PageShell>
          <Notice title="This quotation was declined">{contact}</Notice>
        </PageShell>
      );
    case "ACCEPTED":
      return (
```

```ts
import { checkRateLimit, getPortalDb, getPublicQuote } from "@ace/core";
import { QuotePdf } from "@ace/ui/quote-pdf";
import { renderToBuffer } from "@react-pdf/renderer";
import { getVisitor } from "@/lib/visitor";

export const dynamic = "force-dynamic";

const NO_STORE = { "Cache-Control": "private, no-store" };

export async function GET(_request: Request, { params }: { params: Promise<{ token: string }> }) {
  const { token } = await params;
  const visitor = await getVisitor();
  const db = getPortalDb();
  // A route can answer with a real 429 (a page cannot).
  if (!(await checkRateLimit(db, "view", visitor.ipHash)).allowed) {
    return new Response("Too many requests. Please try again in a few minutes.", {
      status: 429,
      headers: { ...NO_STORE, "Retry-After": "600" },
    });
  }
  const quote = await getPublicQuote(db, token);
  // Issued (open or expired), accepted and declined quotes only; anything else is the same 404.
  const allowed = ["OPEN", "EXPIRED", "ACCEPTED", "DECLINED"];
  if (!quote.found || !allowed.includes(quote.state)) {
    return new Response("Not found", { status: 404, headers: NO_STORE });
  }
  // Called as a function so the element is typed as the Document renderToBuffer expects (QuotePdf stays hook-free).
  const buffer = await renderToBuffer(QuotePdf({ doc: quote.doc }));
  const filename = `${quote.reference.replaceAll(" ", "-")}.pdf`;
  return new Response(new Uint8Array(buffer), {
    headers: {
      ...NO_STORE,
      "Content-Type": "application/pdf",
      "Content-Disposition": `inline; filename="${filename}"`,
    },
  });
}
```
